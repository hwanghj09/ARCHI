# ARCHI

정수호 스프라이트를 사용하는 2D 횡스크롤 사이드뷰 웹게임 기본 틀.

`index.html`을 브라우저에서 열면 실행됩니다. 서버나 빌드 과정은 필요하지 않습니다.

게임은 17층 사무실의 켜진 컴퓨터 앞에서 시작합니다. E 또는 화면의 상호작용 버튼을 누르면 컴퓨터 바탕화면이 열립니다. 파일 폴더에는 조직 안내, 주간 현황, 회의록, 성능 검증, 야간 설비, 출입 안내, 자료 보안, 인수인계 등 사내 문서 8개가 있습니다. 제목·담당자·문서번호 검색과 분류 선택으로 자료를 찾고 본문을 열어 읽을 수 있습니다. 사원증은 PC에 표시하지 않으며 기존 이미지 에셋만 보관합니다. 문서 내용은 게임 기획에 기반한 가상 자료이며 `computer-documents.js`에서 편집합니다.

업무 메모를 입력해 저장할 수 있습니다. 메모는 현재 브라우저의 로컬 저장소에 보관되며, 저장 실패 시 입력 내용은 현재 게임 세션에 유지됩니다. 컴퓨터를 조작하는 동안 캐릭터는 움직이지 않습니다. Escape는 열린 창을 먼저 닫고, 바탕화면에서 다시 누르거나 작업 표시줄의 종료 버튼을 누르면 게임으로 돌아옵니다. 진입·종료 모두 검은색 페이드를 적용합니다. 왼쪽 출입문까지 이동해 E를 누르면 17층 복도로 나갑니다.

17층에서는 상단 조명 체크박스로 사무실과 복도의 조명을 함께 켜거나 끕니다. 조명을 끄면 플레이어 주변만 부드럽게 보이고 반경 210px 바깥은 검게 가려집니다. 시야는 이동·점프를 따라가며 안내 표시는 계속 보입니다. 다른 층과 옥상에는 영향을 주지 않으며, 17층으로 돌아오면 조명 상태가 유지됩니다.

사무실·옥상 왕복과 엘리베이터 탑승·하차는 모두 검은색 페이드로 전환합니다. 약 0.35초 동안 어두워진 뒤 완전히 검어진 시점에 화면을 바꾸고, 약 0.35초 동안 다시 밝아집니다. 전환 중에는 이동·클릭·키보드 입력을 막고 완료 후 포커스를 복구합니다.

- 이동: A / D 또는 좌우 방향키, 화면의 ←/→ 버튼
- 달리기: Shift를 누른 채 이동 (걷기 200px/s, 달리기 340px/s). Shift를 떼면 걷기로 돌아오며 점프 중에는 점프·낙하 스프라이트를 유지합니다.
- 점프: Space / W / 위 방향키, 화면의 ↑ 버튼
- 상호작용: 가까이 서서 E, 화면의 E 버튼 (엘리베이터 호출·탑승 / 문 열기·닫기 / 층 이동)
- 사무실 출입: 시작 지점에 가까운 유리문에서 E로 들어가고, 내부 유리문에서 E로 나옵니다. 내부 문은 복도에서 본 것처럼 유리벽 왼쪽에서 39% 지점에 있고, 켜진 컴퓨터 책상은 그 왼쪽에 있습니다. 입구와 출구는 각각 하나이며 퇴실하면 들어온 위치로 돌아옵니다. 기존 두 번째 문은 배경에서도 제거하고 고정 유리 파티션으로 바꿨습니다.
- 층 이동: 도착한 엘리베이터 앞에서 E를 누르면 1인칭 내부 화면이 열립니다. 마우스로 층을 선택하면 잠시 후 문이 닫히고 이동합니다. 문 닫기 버튼으로 바로 출발 준비를 하거나, 문 열기로 출발을 취소할 수 있습니다. 도착해 문이 완전히 열리면 나가기 버튼이나 Escape로 하차합니다. 15~12층 버튼은 사원증 인증 층이라, 16층 카페 테이블에서 조현아 팀장의 사원증을 챙기기 전에는 눌리지 않고 수호의 출입증이 "미등록"으로 거부됐다는 안내만 나옵니다(`cabin.js`의 `badgeFloors`, 물건 `f16-badge`).

17층 복도에서 중력, 바닥과 벽 충돌, 카메라 추적을 확인할 수 있습니다. 통로의 박스 장애물은 제거되어 점프 없이 이동할 수 있습니다.
점프는 착지한 상태에서만 가능합니다. 걷기는 256×256 스프라이트 6프레임이며, 한 주기당 이동 거리 184px(약 0.92초)을 유지합니다.
공중에서는 상승 중 점프 프레임, 하강 중 낙하 프레임을 사용합니다. 엘리베이터 3개와 비상계단 문은 가까이 서면 강조되며 E로 열고 닫습니다. 문을 조작하면 조사→상호작용 2프레임이 0.42초 동안 재생되며, 이동·점프·포커스 해제 시 종료됩니다.
엘리베이터 3대는 층을 바꿔도 각각의 위치와 문 상태를 유지합니다(처음엔 모두 1층 대기). 호출과 탑승 이동은 한 층당 1.2초이며 표시창에 상승·하강 방향과 현재 층이 표시됩니다. 지하 1층과 1층 사이에 0층은 없습니다. 이동 중 문 열기·층 재선택·하차는 막히며, 내부 비상벨은 소리를 냅니다. 모바일에서는 내부 화면을 가로로 스크롤할 수 있고 탑승 시 버튼 패널이 먼저 보입니다.

B2·B1·1~17층 총 19개 층을 엘리베이터로 연결했습니다. 옥상은 엘리베이터에서 제외하며, 17층 오른쪽 비상계단 앞에서 E를 누르면 올라갑니다. 옥상 왼쪽 계단문에서 E를 누르면 17층으로 돌아옵니다. 옥상은 2400px 폭이며 야경 배경, 돌아오는 계단문, 화면이 꺼진 태양광 임시 전력장치가 있습니다. 전력장치는 현재 배치만 되어 있고 전원 공급 기능과 충돌은 없습니다. 기존 17층 복도와 사무실은 유지합니다. 16~13층은 1층 층별 안내(`층별안내.md`)를 따릅니다. 16층은 The Kitchen·CU 편의점·Café가 있는 편의시설 층입니다. 크림색 타일 마감(food 테마) 복도의 엘리베이터 왼쪽에 벽을 맞댄 사내 식당 The Kitchen(메뉴 라이트박스가 있는 유리벽, 전면 가운데 양문)과 CU 편의점(진열창과 꺼진 간판, 셔터), 화장실 오른쪽에 카페(목재 루버, 전면 왼쪽 끝 문)가 있고 비상계단 옆에는 메뉴 입간판이 있습니다. 방 안 폭은 복도 전면 폭의 3.4배(1060/600/560px → 3604/2040/1904px)입니다. 코드는 `js/` 아래 기능별 파일로 나뉘어 있습니다. 모두 일반(classic) 스크립트라 최상위 선언을 전역으로 함께 쓰고, `index.html`에서 불러오는 순서가 곧 의존 순서입니다. 빌드 도구 없이 `index.html`을 바로 열어도 동작합니다.

- `js/core/`: 설정값(`config.js`), 공용 DOM(`dom.js`), 공용 상태(`state.js`), 게임 루프(`loop.js`)

- `js/world/`: 17층 고정 장면(`office17.js`, `corridor17.js`), 옥상 배경(`rooftop.js`), 물리 월드(`physics.js`)
- `js/scene/`: 문 DOM(`doors.js`), 카메라(`camera.js`), 장면 전환(`transition.js`), 장면 조립(`scene-builder.js`), 층·방 이동(`floor-change.js`)
- `js/player/player.js`: 플레이어 움직임 상태와 애니메이션
- `js/interaction/`: 상호작용(`interaction.js`), 도어락 키패드(`keypad.js`), 전화·순서 소품(`puzzles.js`)
- `js/elevator/`: 엘리베이터 운행(`elevators.js`), 엘리베이터 내부 화면(`cabin.js`)
- `js/computer/`: 17층 컴퓨터(`computer.js`)와 문서 데이터(`documents.js`)
- `js/input/`: 입력 상태(`input.js`), 키보드(`keyboard.js`), 화면 버튼(`touch.js`)
- `js/ui/status.js`(상태 문구), `js/debug/floor-select.js`(테스트용 층 이동), `js/main.js`(맨 마지막에 불러와 첫 화면을 그리고 루프 시작)
