# ARCHI

정수호 스프라이트를 사용하는 2D 횡스크롤 사이드뷰 웹게임 기본 틀.

2~10층(7층 제외)의 단면 배경·벽·문 에셋은 커밋 c872fa507394fbe6d300337048331428ca0cd7a8 기준입니다. 배경에 그려진 물건에는 투명한 조사 영역을 맞추고, 방 문은 닫힘·열림 스프라이트를 사용합니다. 교체되어 사라진 방에서 저장한 진행은 소지품과 기록을 보존하여 같은 층 복도에서 재개합니다.

`index.html`을 브라우저에서 열면 메인 메뉴가 표시됩니다. 계속하기·새 게임·설정·조작 방법을 선택할 수 있으며, 메인 메뉴에서는 게임 시간이 흐르지 않습니다. 설정의 전체 음량(0~100%)과 화면 밝기(75~125%)는 즉시 적용되고 브라우저에 저장됩니다. 전체화면 버튼은 지원되는 브라우저에서 실제 전체화면을 켜고 끕니다. 서버나 빌드 과정은 필요하지 않습니다.

소리는 `js/audio/audio.js`에서 직접 합성합니다. 실제 이동·달리기·착지의 발걸음, 문·엘리베이터 개폐와 도착·비상벨, 정전과 깜빡임, 경비 로봇의 모터·감지·팔 잡기, 휴대폰·충전·전력 레버, 물건 획득(가방에 넣는 소지품은 밝은 차임)·사용(철컥·삑)·거부(도어락 오답과 인증 게이트의 낮은 버저), 셔터(11층 방화셔터·16층 CU)에 효과음이 연결됩니다. 당직 전화는 게임 시간에 맞춰 반복해서 울리고 응답하면 멈춥니다. 사무실 환기음·정전 중 낮은 환경음·옥상 바람·엘리베이터 이동음을 작게 겹치고 로봇 소리는 거리에 따라 줄어듭니다. 처음 클릭이나 키 입력에서 오디오를 활성화하며 메뉴·숨김 탭에서는 게임음을 멈춥니다. 전체 음량을 0으로 설정하면 환경음과 효과음이 함께 꺼집니다. 외부 음원이나 네트워크 요청이 없어 오프라인에서도 재생하며 별도 음원 라이선스가 필요하지 않습니다.

진행 상황은 같은 브라우저의 자동 저장 슬롯에 2초마다 저장하며, 탭이 숨겨지거나 페이지를 닫을 때도 즉시 저장합니다. 게임 중 Esc 또는 상단 메뉴 버튼으로 저장 후 메인 메뉴를 열 수 있습니다. 메인 메뉴에서는 저장 내용을 덮어쓰거나 게임 시간을 진행하지 않습니다. 계속하기는 위치·층과 방·아이템과 출입 인증·퍼즐 단계·이동식 발판·임시 자동문·정신력·휴대폰 배터리와 충전함 보관 위치·태양광 전력·엘리베이터 이동 상태를 복원합니다. 창을 닫은 동안에는 게임 시간이 흐르지 않습니다. 조사창은 닫힌 상태로 재개하고, 오프닝·정전 컷씬은 조작 가능한 상태로, 로봇에게 붙잡힌 경우는 로비 엘리베이터 앞에서 재개합니다. 새 게임은 기존 저장을 덮어쓰기 전에 확인하며 게임 진행과 메모를 초기화하고 음량·밝기 설정은 유지합니다. 저장소를 사용할 수 없으면 저장 실패를 안내하고 게임은 계속 실행합니다.

메인 메뉴에서 새 게임을 누르면 17층 사무실의 5.4초짜리 퇴근 컷씬이 재생됩니다. 수호는 모니터를 향해 앉은 뒷모습으로 작업을 마치고 컴퓨터를 끈 뒤, 오른쪽으로 돌아 의자에서 일어납니다. Esc 또는 ‘건너뛰기’ 버튼으로 즉시 조작을 시작할 수 있습니다. 컷씬 후 E 또는 화면의 상호작용 버튼을 누르면 컴퓨터를 다시 켜 바탕화면을 엽니다. 정전되면 켜 둔 컴퓨터도 꺼지고, 17층에 전력이 없는 동안에는 켜지지 않습니다(‘E · 전원 없음’). 옥상 태양광 비상 전력을 17층에 보내면 다시 켤 수 있습니다. 파일 폴더에는 조작 키 안내, 조직 안내, 주간 현황, 회의록, 성능 검증, 야간 설비, 출입 안내, 자료 보안, 인수인계 등 문서 9개가 있습니다. 제목·담당자·문서번호 검색과 분류 선택으로 자료를 찾고 본문을 열어 읽을 수 있습니다. 사원증은 PC에 표시하지 않으며 기존 이미지 에셋만 보관합니다. 문서 내용은 게임 기획에 기반한 가상 자료이며 `js/computer/documents.js`에서 편집합니다.

업무 메모를 입력해 저장할 수 있습니다. 메모는 현재 브라우저의 로컬 저장소에 보관되며, 저장 실패 시 입력 내용은 현재 게임 세션에 유지됩니다. 컴퓨터를 조작하는 동안 캐릭터는 움직이지 않습니다. Escape는 열린 창을 먼저 닫고, 바탕화면에서 다시 누르거나 작업 표시줄의 종료 버튼을 누르면 게임으로 돌아옵니다. 진입·종료 모두 검은색 페이드를 적용합니다. 왼쪽 출입문까지 이동해 E를 누르면 17층 복도로 나갑니다.

17층에서는 상단 조명 체크박스로 사무실과 복도의 조명을 함께 켜거나 끕니다. 조명을 끄면 플레이어 주변만 부드럽게 보이고 반경 210px 바깥은 검게 가려집니다. 시야는 이동·점프를 따라가며 안내 표시는 계속 보입니다. 다른 층과 옥상에는 영향을 주지 않으며, 17층으로 돌아오면 조명 상태가 유지됩니다.

사무실·옥상 왕복과 엘리베이터 탑승·하차는 모두 검은색 페이드로 전환합니다. 약 0.35초 동안 어두워진 뒤 완전히 검어진 시점에 화면을 바꾸고, 약 0.35초 동안 다시 밝아집니다. 전환 중에는 이동·클릭·키보드 입력을 막고 완료 후 포커스를 복구합니다.

- 이동: A / D 또는 좌우 방향키, 화면의 ←/→ 버튼
- 가방: Tab 또는 오른쪽 위 가방 버튼. 소지품에 마우스를 올리거나 키보드로 포커스하거나 터치하면 설명을 확인합니다. 출입증·사원증은 눌러서 크게 보며, 닫기·E·Escape로 가방 목록에 돌아갑니다. 가방 안에서 Tab·Shift+Tab으로 항목을 선택합니다. Escape·닫기 버튼으로 가방을 닫으며, 카드를 보는 중에 가방 버튼을 누르면 가방을 바로 닫습니다. 현재 옥상 열쇠를 보관하며, 새로고침하면 다른 게임 진행 상태와 함께 초기화됩니다.
- 옥상 열쇠: 17층 복도 오른쪽 소화전 앞에서 E를 눌러 내부를 열고, 호스 아래의 낡은 열쇠를 직접 클릭해야 획득합니다(Tab으로 선택 후 Enter/Space도 가능). 조사만 하거나 창을 닫으면 획득되지 않습니다. 열쇠를 가진 상태에서 비상계단 앞의 E를 누르면 ‘열쇠 사용하기’ 버튼이 나타나며, 직접 눌러야 잠금이 풀리고 옥상으로 올라갑니다. 닫거나 이동하면 사용을 취소합니다. 한 번 잠금을 해제한 뒤에는 E로 바로 왕복하며, 열쇠는 사용 후에도 가방에 남습니다.
- 달리기: Shift를 누른 채 이동 (걷기 200px/s, 달리기 340px/s). Shift를 떼면 걷기로 돌아오며 점프 중에는 점프·낙하 스프라이트를 유지합니다.
- 점프: Space / W / 위 방향키, 화면의 ↑ 버튼
- 상호작용: 가까이 서서 E, 화면의 E 버튼 (엘리베이터 호출·탑승 / 문 열기·닫기 / 층 이동)
- 휴대폰: P 또는 화면의 휴대폰 버튼으로 열고, 실제 기기 이미지 위의 배터리·플래시 화면을 조작합니다. F나 화면 버튼으로 플래시를 켜고 끕니다. 플래시가 켜져 있을 때만 화면을 닫은 뒤에도 휴대폰을 들고 걷습니다. OFF 또는 배터리 소진 시 자동으로 넣고 빈손으로 이동하며 Shift로 달릴 수 있습니다. 별도 들기·넣기 버튼은 없습니다. 빛은 휴대폰에서 바라보는 방향으로 나가며, 켜져 있는 동안 배터리는 초당 1%씩 줄어듭니다. P/Esc 또는 화면 하단 홈 바로 닫습니다.
- 조사 UI: 소품을 조사하면 화면 하단 대화창에 내용이 열립니다. 글이 적힌 물건은 그 물건 모습 그대로 크게 펼쳐집니다. 화이트보드·노트·일지·게시판·칠판·포스트잇은 손글씨로, 출력물·서류·공지문·안내판·포스터·증서·감사패는 종이와 명패로, 모니터·콘솔·제어함 액정은 화면으로, 영수증·라벨·스티커·명판·꼬리표·사원증은 그 생김새로 보입니다(볼펜 메모, 도장, 형광펜, 매직으로 지운 칸, 지운 자국, 진행 막대 포함). 길면 Page Up/Down으로 넘겨 봅니다. E·Escape·닫기 버튼으로 닫거나 이동을 시작하면 자동으로 접힙니다. 모든 층의 화장실에서도 수납장, 휴지통, 표지, 세면대 거울, 화장실 칸, 비상 호출 버튼을 조사할 수 있습니다.
- 사무실 출입: 시작 지점에 가까운 유리문에서 E로 들어가고, 내부 유리문에서 E로 나옵니다. 내부 문은 복도에서 본 것처럼 유리벽 왼쪽에서 39% 지점에 있고, 켜진 컴퓨터 책상은 그 왼쪽에 있습니다. 입구와 출구는 각각 하나이며 퇴실하면 들어온 위치로 돌아옵니다. 기존 두 번째 문은 배경에서도 제거하고 고정 유리 파티션으로 바꿨습니다.
- 층 이동: 도착한 엘리베이터 앞에서 E를 누르면 1인칭 내부 화면이 열립니다. 마우스로 층을 선택하면 잠시 후 문이 닫히고 이동합니다. 문 닫기 버튼으로 바로 출발 준비를 하거나, 문 열기로 출발을 취소할 수 있습니다. 도착해 문이 완전히 열리면 나가기 버튼이나 Escape로 하차합니다. 12~15층도 출입증 없이 선택하고 내릴 수 있습니다. 하차 로비 양쪽의 유리 인증 게이트 앞에서 E로 사원증을 태그해야 업무 구역에 들어갈 수 있습니다. 수호의 출입증은 17층 사무실 책상 위에서 E로 챙기며 가방(Tab)에서 다시 확인할 수 있습니다. 수호의 카드는 "미등록"으로 거부되고(거부 화면과 휴대폰 건물 안내 앱이 "16층 Café에서 마지막 확인"이라고 알려 줍니다), 16층 카페에서 얻는 조현아 팀장의 사원증(`f16-badge`)으로 층마다 인증하면 양쪽 통로가 열립니다. 인증은 재방문해도 유지됩니다.
