# ARCHI

정수호 스프라이트를 사용하는 2D 횡스크롤 사이드뷰 웹게임 기본 틀.

`index.html`을 브라우저에서 열면 실행됩니다. 서버나 빌드 과정은 필요하지 않습니다.

- 이동: A / D 또는 좌우 방향키, 화면의 ←/→ 버튼
- 점프: Space / W / 위 방향키, 화면의 ↑ 버튼
- 상호작용: 가까이 서서 E, 화면의 E 버튼 (엘리베이터 호출·탑승 / 문 열기·닫기 / 층 이동)
- 사무실 출입: 시작 지점에 가까운 유리문에서 E로 들어가고, 내부 왼쪽 문에서 E로 나옵니다. 입구와 출구는 각각 하나이며 퇴실하면 들어온 위치로 돌아옵니다. 기존 두 번째 문은 배경에서도 제거하고 고정 유리 파티션으로 바꿨습니다.
- 층 이동: 도착한 엘리베이터 앞에서 E를 누르면 1인칭 내부 화면이 열립니다. 마우스로 층을 선택하면 잠시 후 문이 닫히고 이동합니다. 문 닫기 버튼으로 바로 출발 준비를 하거나, 문 열기로 출발을 취소할 수 있습니다. 도착해 문이 완전히 열리면 나가기 버튼이나 Escape로 하차합니다.

17층 복도에서 중력, 바닥과 벽 충돌, 장애물 착지, 카메라 추적을 확인할 수 있습니다.
점프는 착지한 상태에서만 가능합니다. 걷기는 256×256 스프라이트 6프레임이며, 한 주기당 이동 거리 184px(약 0.92초)을 유지합니다.
공중에서는 상승 중 점프 프레임, 하강 중 낙하 프레임을 사용합니다. 엘리베이터 3개와 비상계단 문은 가까이 서면 강조되며 E로 열고 닫습니다. 문을 조작하면 조사→상호작용 2프레임이 0.42초 동안 재생되며, 이동·점프·포커스 해제 시 종료됩니다.
엘리베이터 3대는 층을 바꿔도 각각의 위치와 문 상태를 유지합니다(처음엔 모두 1층 대기). 호출과 탑승 이동은 한 층당 1.2초이며 표시창에 상승·하강 방향과 현재 층이 표시됩니다. 지하 1층과 1층 사이에 0층은 없습니다. 이동 중 문 열기·층 재선택·하차는 막히며, 내부 비상벨은 소리를 냅니다. 모바일에서는 내부 화면을 가로로 스크롤할 수 있고 탑승 시 버튼 패널이 먼저 보입니다.

B2·B1·1~17층 총 19개 층을 연결했습니다. 옥상은 제외했습니다. 기존 17층 복도와 사무실은 유지하고, 나머지 18개 층은 2400px 폭의 빈 공간으로 구성했습니다. 바닥·양쪽 벽·돌아갈 엘리베이터 3대만 있으며 소품, 장애물, NPC, 퍼즐은 없습니다.

맵 길이, 바닥 높이, 이동 속도, 장애물 배치는 `player.js`의 상수와 `terrain`에서 조정합니다.
17층 배경은 `assets/background/floor17/tiles/`의 256×256 PNG 39장으로 구성됩니다.
`player.js`에서 13열 × 3행으로 연결하며, 바닥선은 충돌 좌표와 같은 y=570입니다.
조립된 아틀라스, 생성 원본, 내보내기 규격과 프롬프트는 `assets/background/floor17/`에 있습니다.
문은 `assets/objects/floor17/`의 별도 PNG 시트를 사용합니다. 프레임은 256×512, 시트는 512×512(왼쪽 닫힘 / 오른쪽 열림)이며 기존 배경의 문 위치를 덮어 표시합니다.
화면 크기를 바꿔도 플레이어의 월드 좌표는 유지됩니다.

물리 엔진은 [Matter.js 0.20.0](https://github.com/liabru/matter-js/tree/0.20.0)입니다.
오프라인 실행을 위해 배포본을 `assets/vendor/`에 포함했으며 MIT 라이선스를 함께 보관합니다.

검증: `npm ci` 후 `npx playwright install chromium`, `npm test`.
