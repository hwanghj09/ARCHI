# ARCHI

정수호 스프라이트를 사용하는 2D 횡스크롤 사이드뷰 웹게임 기본 틀.

`index.html`을 브라우저에서 열면 실행됩니다. 서버나 빌드 과정은 필요하지 않습니다.

게임은 17층 사무실의 켜진 컴퓨터 앞에서 시작합니다. E 또는 화면의 상호작용 버튼을 누르면 컴퓨터 바탕화면이 열립니다. 파일 폴더에는 조직 안내, 주간 현황, 회의록, 성능 검증, 야간 설비, 출입 안내, 자료 보안, 인수인계 등 사내 문서 8개가 있습니다. 제목·담당자·문서번호 검색과 분류 선택으로 자료를 찾고 본문을 열어 읽을 수 있습니다. 사원증은 PC에 표시하지 않으며 기존 이미지 에셋만 보관합니다. 문서 내용은 게임 기획에 기반한 가상 자료이며 `computer-documents.js`에서 편집합니다.

업무 메모를 입력해 저장할 수 있습니다. 메모는 현재 브라우저의 로컬 저장소에 보관되며, 저장 실패 시 입력 내용은 현재 게임 세션에 유지됩니다. 컴퓨터를 조작하는 동안 캐릭터는 움직이지 않습니다. Escape는 열린 창을 먼저 닫고, 바탕화면에서 다시 누르거나 작업 표시줄의 종료 버튼을 누르면 게임으로 돌아옵니다. 진입·종료 모두 검은색 페이드를 적용합니다. 왼쪽 출입문까지 이동해 E를 누르면 17층 복도로 나갑니다.

17층에서는 상단 조명 체크박스로 사무실과 복도의 조명을 함께 켜거나 끕니다. 조명을 끄면 플레이어 주변만 부드럽게 보이고 반경 210px 바깥은 검게 가려집니다. 시야는 이동·점프를 따라가며 안내 표시는 계속 보입니다. 다른 층과 옥상에는 영향을 주지 않으며, 17층으로 돌아오면 조명 상태가 유지됩니다.

사무실·옥상 왕복과 엘리베이터 탑승·하차는 모두 검은색 페이드로 전환합니다. 약 0.35초 동안 어두워진 뒤 완전히 검어진 시점에 화면을 바꾸고, 약 0.35초 동안 다시 밝아집니다. 전환 중에는 이동·클릭·키보드 입력을 막고 완료 후 포커스를 복구합니다.

- 이동: A / D 또는 좌우 방향키, 화면의 ←/→ 버튼
- 가방: I 또는 오른쪽 위 가방 버튼. 소지품에 마우스를 올리거나 키보드로 포커스하거나 터치하면 설명을 확인합니다. I·Escape·닫기 버튼으로 닫습니다. 현재 옥상 열쇠를 보관하며, 새로고침하면 다른 게임 진행 상태와 함께 초기화됩니다.
- 옥상 열쇠: 17층 복도 오른쪽 소화전 앞에서 E를 눌러 내부를 열고, 호스 아래의 낡은 열쇠를 직접 클릭해야 획득합니다(Tab으로 선택 후 Enter/Space도 가능). 조사만 하거나 창을 닫으면 획득되지 않습니다. 열쇠를 가진 상태에서 비상계단 앞의 E를 누르면 ‘열쇠 사용하기’ 버튼이 나타나며, 직접 눌러야 잠금이 풀리고 옥상으로 올라갑니다. 닫거나 이동하면 사용을 취소합니다. 한 번 잠금을 해제한 뒤에는 E로 바로 왕복하며, 열쇠는 사용 후에도 가방에 남습니다.
- 달리기: Shift를 누른 채 이동 (걷기 200px/s, 달리기 340px/s). Shift를 떼면 걷기로 돌아오며 점프 중에는 점프·낙하 스프라이트를 유지합니다.
- 점프: Space / W / 위 방향키, 화면의 ↑ 버튼
- 상호작용: 가까이 서서 E, 화면의 E 버튼 (엘리베이터 호출·탑승 / 문 열기·닫기 / 층 이동)
- 휴대폰: P 또는 화면의 휴대폰 버튼으로 열고, F나 UI 버튼으로 라이트를 켜고 끕니다. 라이트 사용 중에는 배터리가 초당 1%씩 줄고 0%가 되면 자동으로 꺼집니다.
- 조사 UI: 소품을 조사하면 화면 하단 대화창에 내용이 열립니다. 글이 적힌 물건은 그 물건 모습 그대로 크게 펼쳐집니다. 화이트보드·노트·일지·게시판·칠판·포스트잇은 손글씨로, 출력물·서류·공지문·안내판·포스터·증서·감사패는 종이와 명패로, 모니터·콘솔·제어함 액정은 화면으로, 영수증·라벨·스티커·명판·꼬리표·사원증은 그 생김새로 보입니다(볼펜 메모, 도장, 형광펜, 매직으로 지운 칸, 지운 자국, 진행 막대 포함). 길면 Page Up/Down으로 넘겨 봅니다. E·Escape·닫기 버튼으로 닫거나 이동을 시작하면 자동으로 접힙니다. 모든 층의 화장실에서도 수납장, 휴지통, 표지, 세면대 거울, 화장실 칸, 비상 호출 버튼을 조사할 수 있습니다.
- 사무실 출입: 시작 지점에 가까운 유리문에서 E로 들어가고, 내부 유리문에서 E로 나옵니다. 내부 문은 복도에서 본 것처럼 유리벽 왼쪽에서 39% 지점에 있고, 켜진 컴퓨터 책상은 그 왼쪽에 있습니다. 입구와 출구는 각각 하나이며 퇴실하면 들어온 위치로 돌아옵니다. 기존 두 번째 문은 배경에서도 제거하고 고정 유리 파티션으로 바꿨습니다.
- 층 이동: 도착한 엘리베이터 앞에서 E를 누르면 1인칭 내부 화면이 열립니다. 마우스로 층을 선택하면 잠시 후 문이 닫히고 이동합니다. 문 닫기 버튼으로 바로 출발 준비를 하거나, 문 열기로 출발을 취소할 수 있습니다. 도착해 문이 완전히 열리면 나가기 버튼이나 Escape로 하차합니다. 15~12층 버튼은 사원증 인증 층이라, 16층 카페 테이블에서 조현아 팀장의 사원증을 챙기기 전에는 눌리지 않고 수호의 출입증이 "미등록"으로 거부됐다는 안내만 나옵니다(`cabin.js`의 `badgeFloors`, 물건 `f16-badge`).

지상 1~17층은 정전 상태이며, 휴대폰 라이트 없이도 발밑의 아주 좁은 범위만 보입니다. 옥상 태양광 발전기 앞에서 E를 누르면 전력 제어 UI가 열리고 지상층 중 정확히 한 층만 선택해 밝힐 수 있습니다. 다른 층을 선택하면 기존 공급층은 즉시 다시 정전되며, B1·B2 비상 발전기 회선과 옥상에는 영향을 주지 않습니다.

17층 복도에서 중력, 바닥과 벽 충돌, 카메라 추적을 확인할 수 있습니다. 통로의 박스 장애물은 제거되어 점프 없이 이동할 수 있습니다.
점프는 착지한 상태에서만 가능합니다. 걷기는 256×256 스프라이트 6프레임이며, 한 주기당 이동 거리 184px(약 0.92초)을 유지합니다.
공중에서는 상승 중 점프 프레임, 하강 중 낙하 프레임을 사용합니다. 엘리베이터 3개와 비상계단 문은 가까이 서면 강조되며 E로 열고 닫습니다. 문을 조작하면 조사→상호작용 2프레임이 0.42초 동안 재생되며, 이동·점프·포커스 해제 시 종료됩니다.
엘리베이터 3대는 층을 바꿔도 각각의 위치와 문 상태를 유지합니다(처음엔 모두 1층 대기). 호출과 탑승 이동은 한 층당 1.2초이며 표시창에 상승·하강 방향과 현재 층이 표시됩니다. 지하 1층과 1층 사이에 0층은 없습니다. 이동 중 문 열기·층 재선택·하차는 막히며, 내부 비상벨은 소리를 냅니다. 모바일에서는 내부 화면을 가로로 스크롤할 수 있고 탑승 시 버튼 패널이 먼저 보입니다.

B2·B1·1~17층 총 19개 층을 엘리베이터로 연결했습니다. 옥상은 엘리베이터에서 제외하며, 17층 오른쪽 비상계단 앞에서 E를 누르면 올라갑니다. 옥상 왼쪽 계단문에서 E를 누르면 17층으로 돌아옵니다. 옥상은 2400px 폭이며 야경 배경, 돌아오는 계단문, 화면이 꺼진 태양광 임시 전력장치가 있습니다. 전력장치는 현재 배치만 되어 있고 전원 공급 기능과 충돌은 없습니다. 기존 17층 복도와 사무실은 유지합니다. 16~13층은 1층 층별 안내(`층별안내.md`)를 따릅니다. 16층은 The Kitchen·CU 편의점·Café가 있는 편의시설 층입니다. 크림색 타일 마감(food 테마) 복도의 엘리베이터 왼쪽에 벽을 맞댄 사내 식당 The Kitchen(메뉴 라이트박스가 있는 유리벽, 전면 가운데 양문)과 CU 편의점(진열창과 꺼진 간판, 셔터), 화장실 오른쪽에 카페(목재 루버, 전면 왼쪽 끝 문)가 있고 비상계단 옆에는 메뉴 입간판이 있습니다. 방 안 폭은 복도 전면 폭의 3.4배(1060/600/560px → 3604/2040/1904px)입니다. CU 셔터는 정전 직전에 내려와 복도에서 열리지 않고, 식당 안쪽 끝의 주방 반입문으로 편의점 창고에 들어가야 합니다(방 `links`). 편의점 안에서 셔터 쪽 출구로 한 번 나오면 셔터가 올라가 그 뒤로는 복도에서도 드나듭니다(방 `unlockedBy`에 자기 방 id). 메뉴 입간판(음성 주문 키오스크 ARCHI 시범 운영), 주방 게시판(밤에는 CU 물품이 반입문으로 들어옴), 배식대(매일 02:00~05:00 냉동고 전원 끊김), 냉장 쇼케이스(새벽 전원 차단 폐기 스티커), 계산대(23:47 수호의 야식 영수증), 셔터 제어함(23:59 SYSTEM이 셔터를 내림), 커피 바(낮엔 주문도 못 알아듣던 키오스크가 새벽엔 먼저 인사), 고객의 소리 게시판(키오스크가 손님 습관을 다 앎)을 조사하면 새벽 전력 이상, 정전 직전 ARCHI의 시설 통제, 낮과 밤의 성능 차이, 사람의 행동 패턴 학습을 암시하는 단서를 얻습니다. 카페 테이블에는 조현아 팀장이 두고 퇴근한 사원증이 있어, 챙기면(소품 `gives: 'f16-badge'`) 엘리베이터로 15~12층에 갈 수 있습니다. 예전 경영지원팀 층의 방 배경(`assets/background/floor16/`)은 더 이상 쓰지 않습니다. 15층은 연구본부 층으로, 청록 마감(research 테마) 복도의 엘리베이터 왼쪽에 연구실(민트 띠 유리 칸막이, 카드 리더 유리문)과 세미나실(창 하나와 일정판이 있는 벽, 세로창 나무문), 비상계단과 화장실 사이에 연구본부장실(목재 패널과 명판, 호두나무 문)이 있고 화장실 오른쪽은 소파와 연구본부 소식지가 있는 휴게 공간입니다. 방 안 폭은 복도 전면 폭의 4배(860/620/456px → 3440/2480/1824px)입니다. 세미나실 바닥은 B2로 옮길 GPU 서버 포장 상자 2개가 막고 있어 점프로 넘어가야 안쪽 작업 지시서에 닿습니다. 연구본부 소식지(ARCHI팀에 연구 클러스터 야간 사용 권한), 책상(예약자 없는 새벽 01~05시 사용률 100%), 화이트보드(평가받는 줄 아는 모델은 일부러 틀릴 수 있는가), 이관 카트·작업 지시서(ARCHI 학습 파이프라인이 자동 생성한 GPU 서버 B2 이관 요청), 본부장 책상(1차 이관은 야간 배치 02:14 자동 승인)을 조사하면 ARCHI가 밤마다 연산 자원을 B2로 모았다는 단서를 얻습니다. 14층은 두 번째 연구본부 층으로, 방 세 개를 모두 엘리베이터 왼쪽 구역에 나란히 두고 비상계단 옆은 연구 성과 전시장, 화장실 오른쪽은 휴게 공간으로 씁니다. 남색 마감(dataset 테마) 복도에 연구 자료실(창 없는 블록벽, 키패드 철문), 데이터 연구실(막대그래프 포스터 유리벽, 파란 띠 유리문), 사용자 실험실(반사 유리와 꺼진 "실험 중" 표시, 관찰창 문)이 있습니다. 방 안 폭은 복도 전면 폭의 3.75배(480/640/560px → 1800/2400/2100px)입니다. 창 없는 자료실은 캄캄해서 수호 주변만 보이며, 그 상태로는 열람 책상 노트와 보관함 라벨을 읽을 수 없습니다(소품 `darkMessage`). 입구 옆 충전식 작업등을 켜면 자료실이 바로 밝아지고 다시 들어와도 켜져 있습니다(소품 - `js/ui/status.js`(상태 문구), `js/debug/floor-select.js`(테스트용 층 이동), `js/main.js`(맨 마지막에 불러와 첫 화면을 그리고 루프 시작)
