# ARCHI

Unity project for ARCHI.

## Requirements

- Unity 6000.5.6f1
- Git LFS

## Download

```bash
git lfs install
git clone <repository-url>
cd ARCHI
```

Open the project folder with Unity Hub using Unity `6000.5.6f1`.

## Version Control

Commit these folders/files:

- `Assets/`
- `Packages/`
- `ProjectSettings/`
- `.gitignore`
- `.gitattributes`

Do not commit generated folders such as `Library/`, `Temp/`, `Logs/`, `Build/`, `Builds/`, or `UserSettings/`.
