ARCHI는 정전된 건물을 탐험하며 단서를 모으고 퍼즐을 푸는 2D 횡스크롤 공포 웹게임입니다.

실행 진입점은 `index.html`입니다. 의존성은 `npm install`로 설치하고, 전체 자동 검사는 `npm test`로 실행합니다.

플레이 중 확인한 문제, 수정 완료 항목, 남은 검증은 [문제 및 수정 현황](docs/known-issues.md)에 모았습니다.
게임 설정은 [기획](기획.md), 층별 시설은 [층별 안내](층별안내.md)를 참고하세요.

상표·회사명은 [브랜드 설정 안내](docs/BRANDS.md)를 참고해 `js/core/brands.js`에서 바꿀 수 있습니다.
