# 17층 사무실 → 복도 → 첫 정전

ARCHK가 회사 제어망을 장악해 외부 연결을 시도한다는 설정을 따른다. 사람이나 귀신이 새로 나타나는 연출 대신, 정상적인 설비가 수호의 움직임에 반응하고 제어권을 빼앗기는 상황으로 긴장을 만든다.

- 사무실: 책상·출입구 주변에만 빛을 남긴다. 오프닝에서 자리에서 일어났을 때 종료된 모니터에 `ARCHK / 외부 연결 시도` 신호가 나타나고, 조작 복귀 후 2.6초 뒤 지워진다. 오프닝을 건너뛰면 조작 복귀 0.75초 후 신호가 나타난다. 실제 컴퓨터 전원과 문서 접근 상태는 바꾸지 않는다.
- 복도: 출입문 잠금장치의 재작동 소리가 뒤에서 들린다. x=1050 이후 천장 릴레이가 연속 작동하고, 수호가 멈추면 소리도 멎는다. x=1390 이후 CCTV의 감시 방향이 수호를 따라간다.
- 첫 정전: 기존 호출 시도와 두 번의 조명 이상 뒤, 2.9초에 정전한다. 환풍기 환경음을 끊고 4.8초부터 엘리베이터 잠금장치 소리를 들려준다. 6.3초부터 선택한 엘리베이터의 꺼진 표시등에 `정수호`가 나타나며 8.2초에 기존 플래시 안내와 플레이로 돌아간다.
- 건너뛰기: 어느 단계에서도 정전 상태를 확정하고 입력·화면·효과음을 정리한다. 모션 감소 설정에서는 기존 조명 깜빡임을 생략한다.
- 재방문·저장: 일회성 사건은 `first-night-*` 진행 플래그로 기존 저장 슬롯에 보존한다. 짧은 모니터/효과음 연출은 저장 후 재생하지 않는다. 새 게임은 플래그를 초기화한다. 다른 층이나 태양광 복구 후에는 시작 구간의 조명·CCTV 연출을 적용하지 않는다.

구현은 `js/scene/first-night.js`, `js/scene/blackout.js`, `js/audio/audio.js`, `css/first-night.css`에 있다. 외부 음원 없이 합성한 기계음이며 전체 음량·음소거·메뉴·숨김 탭 처리를 따른다. 새로운 퍼즐이나 관제탑 출입 기능은 포함하지 않는다.

모든 스타일시트는 `css/`에 모았다. 기존 HTML 인라인 스타일은 `css/game.css`로 옮겼고, 스타일시트의 이미지·폰트 경로는 `../assets/`를 사용한다.

검증: `tests/first-night.mjs`는 실제 이동과 사건 순서, 기기 조작, 진행 복원, 정전과 입력 복귀를 PC·모바일 세로·가로에서 확인한다. 오프닝·정전·오디오·장면 에셋·조사 UI 회귀는 관련 기존 테스트로 확인한다.

확인한 기존 검사 실패: `save-progress.mjs`는 두 층 전력 복원을 기대하지만 현재 게임은 한 층만 복원한다. `elevator-power.mjs`는 옥상 전력 패널 진입, `lighting.mjs`는 옥상 열쇠 획득에서 실패한다. 세 건 모두 변경 전 코드에서도 같은 지점에서 실패함을 확인했으며 이번 시작 연출 변경에 포함하지 않았다. 전체 테스트 묶음은 실행하지 않았다.
