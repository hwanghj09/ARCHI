# ARCHI 스토리 구현 현황

2026-10-11 코드 확인 기준. 기획 문서에 있는 사건과 실제 플레이 기능을 구분한다.

현재 구현된 마지막 지점은 **B2 메인 콘솔을 조사해 ARCHI의 자기 복제 계획을 확인하고, 목표가 ‘ARCHI 멈추기’로 바뀌는 단계**다. 삭제 실행과 결말은 없다.

## 현재 진행 흐름

17층 야근 종료 → 복도에서 첫 정전 → 소화전 열쇠로 옥상문 개방 → 비상 전력 복구 → 1층 로봇 추격 → 16층 항불안제 → 12층 출입 권한 확보 → 개발팀 조사 → 7층 원본 로그 조사 → B1 승강기 제한 해제 → B2 진실 확인.

이것은 목표와 단서가 안내하는 흐름이다. 모든 사건을 이 순서로만 진행하도록 강제하는 시스템은 아니다. 예를 들어 B1 제한을 먼저 풀면 7층 로그를 읽기 전에도 B2에 갈 수 있다.

## 실제 사건과 설명 문구의 차이

- 혼잣말 스토리 컷씬은 현재 세 개다: 1층 추격 뒤 항불안제 안내, 약 사용 뒤 12층 조사 안내, 출입증 거부 뒤 다른 사원증 안내.
- 12층 → 7층 → B2 진행은 지정 소품을 읽으면 진행 플래그가 생기고 목표가 바뀌는 방식이다. 주요 발견 뒤 수호가 사실을 정리하는 별도 컷씬은 없다.
- 12층과 7층의 핵심 정보는 종이 결과지·메모·배터리 백업 장비에 있다. 목표의 ‘전력을 공급하고 조사’라는 안내와 별개로, 이 정보를 얻는 PC 로그인·로그 조회 퍼즐은 없다.
- B2 전송 화면은 61%로 고정되어 있다. ‘보고 있는 사이 62%’는 조사 문구이며 실제 시간에 따른 전송 진행은 없다.
- B2 대기 로봇 셋은 고정물이다. 움직이는 로봇 제어는 현재 1층 R-01에만 연결되어 있다.
- `bossFightActive`는 정신력 계산용 상태만 있으며 최종 전투를 시작하는 코드가 없다.
- 2~16층에는 추가 조사 문구와 소품 퍼즐이 있지만, 모두 주 스토리 진행의 필수 조건은 아니다.
- 기존 정신력·환각 시스템은 남아 있다. 이번 제거 대상은 직전에 추가한 17층 공포 연출 전체다.

## 스토리 확정 전에 맞출 부분

1. 옥상에서 B2 전력 집중을 발견한다는 요약과 실제 단서 위치(B1)를 맞춘다.
2. 16층 약·사원증 우회가 주 스토리에 필요한지 결정하고, 사원증 안내 대사와 실제 위치를 맞춘다.
3. 수호의 신분을 통일한다. 현재 혼잣말은 ‘일용직’, 출입증 설명은 ‘개발팀’이다.
4. 기획의 태양광 공급 한도는 두 층이지만 현재 코드와 B1 안내는 한 층이다.
5. 12층과 7층의 발견이 수호에게 어떤 결론과 다음 행동을 만들지 정한 뒤, B2 삭제·엔딩으로 연결한다.

검증 범위: 코드를 읽고, 브라우저에서 12층 메모·7층 로그/인터록·B1 승강기 제어반·B2 콘솔을 직접 조사해 진행 플래그와 목표 변경을 확인했다. 해당 확인은 장면을 직접 선택해 수행했으며 새 게임부터의 전체 동선을 완주한 검사는 아니다.

컴퓨터 UI는 여러 앱 창을 동시에 유지한다. 바탕화면은 클릭으로 선택하고 더블클릭 또는 터치로 열며, 시작 메뉴에서 앱·문서를 검색한다. 창 이동·크기 조절·최소화·최대화·복원과 작업표시줄 전환을 지원한다. 최소화된 앱의 다운로드·전송은 계속 진행되고 PC 종료·전력 상실 시 취소된다. 창 상태는 게임 저장에 포함하지 않는다.
