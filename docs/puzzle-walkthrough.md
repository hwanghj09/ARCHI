# 퍼즐 순서와 해법

본편 진행 순서대로 정리한 퍼즐 목록이다. 순서는 `js/debug/puzzle-skip.js`의 `PUZZLE_STEPS`(본편 목표 순서, `js/ui/objective.js`)를 따른다. 2026-10-24 커밋 `25a3456`(1층 퇴근 흐름 변경)과 그 뒤 작업 트리 수정까지 반영해 다시 확인했다.

1. **17F 정전 컷씬**: 사무실에서 복도로 나가 엘리베이터에 다가가면 저절로 재생된다. 따로 조작할 건 없다.
2. **17F 비상 열쇠함 열쇠·옥상문**: 옥상문 바로 옆 벽의 '비상 열쇠함'에서 낡은 열쇠를 줍고, '비상계단' 문에서 '열쇠 사용하기'를 눌러 옥상으로 올라간다. 소화전에는 이제 열쇠가 없다.
3. **RF 태양광 비밀번호·전선**: 발전기 레버를 내리고 비밀번호 **1997**을 입력한다(17F 'CCTV 아래 게시판' 관리 메모에 적혀 있다). 이어서 전선 4가닥을 같은 색 단자끼리 잇고, 17층 전력을 켠다.
4. **17F 관리실 비밀번호·비상 회선**:
   - 관리자실 문 바로 왼쪽 '청소 카트' 아래칸의 양동이를 치우면 메모(**1706**)가 나온다. 그 번호로 관리실 문을 연다.
   - 관리실 책상의 '회로 안내도'를 보고 분배반 전선을 S1→E3, S2→E1, S3→E4, S4→E2로 이은 뒤 '회로 검사'를 누른다. 안내도를 읽는 것은 더 이상 필수가 아니다(작업 트리 수정).
5. **1F 정문 확인·안내 데스크 전력 앱**:
   - 1층에 내려 어두운 '정문'을 조사해 문이 안 열리는 것을 확인한다.
   - '안내 데스크'에 켜진 휴대폰을 대면 사내 Wi-Fi로 전력 앱이 설치된다. 배터리가 없으면 데스크 왼쪽 콘센트에서 충전한다.
   - 휴대폰 전력 앱으로 1층에 전력을 보낸다.
   - 17F 블로그 apk 내려받기와 USB 파일 전송은 삭제됐다.
6. **1F 경비 로봇 추격**: 1층 전력이 켜지면 컷씬이 나오고 정문 화면에 "출입 차단 · 17F 정수호"가 뜬다. 깨어난 R-01을 피해 엘리베이터 앞까지 도망치면 끝난다.
7. **16F 항불안제**:
   - 식당 'The Kitchen' 안쪽 반입문으로 편의점에 들어간다.
   - '인라면 박스'를 선반 밑까지 밀고 올라서서 약을 줍고, 가방에서 사용한다.
   - 나갈 때는 '셔터 제어함' 레버로 셔터를 올리고 나온다.
8. **1F 로봇 정비 기록**: 경비 로봇 정비 패널에 **0914**를 입력한다. 진열장의 제작일 1107은 옛 번호라 함정이고, 0914는 점검표에 있는 로비 배치일이다.
9. **12F 게이트·출입증 쌔비기**:
   - 내 출입증을 12~15F 게이트에 태그해서 거부당하면 컷씬이 16층 카페에 사원증이 있다고 알려 준다. 17F 옆자리 포스트잇은 삭제됐다.
   - 16F 카페 테이블에서 조현아 팀장 사원증을 주워 게이트에 다시 태그한다. 거부당하기 전에 먼저 챙겨 와도 된다.
10. **12F 로그 삭제 막기**: '야간 로그 단말기'를 열면 삭제가 시작된다. 바로 '네트워크 랙'에서 LAN 케이블을 뽑는다. 늦었다면 '평가 벤치'의 종이 백업을 보고 단말기에서 복구한다.
11. **12F 모델 평가 퀴즈**: 10/07 밤만 성능이 낮은 이유를 묻는데, 답은 **"건물에 사람이 있었음"**이다. 오답은 정신력 -5%다.
12. **5F 서가 꼭대기 노트**: 연구개발실의 '이동식 발판'을 맨 안쪽 서가에 붙인다. 발판에서 점프해 꼭대기에 올라가 노트를 조사한다.
13. **8F 재현 기록**: 제품기획실 화이트보드에서 순서를 확인한다. QA실에서 그 순서대로 시계 03:00, 재실 인원 0명, 카메라 OFF로 맞추고 '재현 벤치'의 실행을 누른다.
14. **7F 백업 장비 · 학습 시간**: '망분리 백업 장비'의 날짜 표를 비교해 **03시**를 고른다. 10/05에 성능이 오르고 B2 전력이 몰린 시간이다.
15. **ARCHI-MAIN 외부 연결 로그**: [오늘] 탭에는 ARCHI가 23:58에 회사 홈페이지(`archi.html`)에 들렀다는 기록만 있다. 게임 밖에서 그 홈페이지를 열어 공지 아래 '임시 저장된 글 1개'를 펼치면 ARCHI가 남긴 SSH 정보(사용자 **archi_svc**, 주소 **10.0.2.24**, 비밀번호 **archi_night03**)가 나온다. 17층 내 자리 컴퓨터(또는 13층 원격지원 PC)의 '터미널'에서 `ssh archi_svc@10.0.2.24`로 접속하고 `cat external.log`로 외부 연결 기록을 읽는다. 읽고 나면 ARCHI가 접속을 끊는다.
16. **13F 보안 자료실 백업 장치**: 13층 전력을 켜고 들어가 '백업 장치 보관함'에서 장치를 챙기면 셔터에 갇힌다. 폰 앱으로 13층 전력을 끈 뒤, 어둠 속에서 '수동 개방 크랭크'를 돌려 나온다.
17. **백업 장치 영상**: 13층 기술지원 상황실의 '원격지원 PC'(UPS로 켜져 있음) 또는 17층 내 자리 컴퓨터의 '외부 저장 장치'에 USB를 연결하고, 영상을 끝까지 본다. 17층 컴퓨터는 17층 전력이 필요하다.
18. **2F 리허설 영상**: 서버실 녹화 NAS에서 디스크를, 휴게실 커피 테이블에서 리모컨을 챙긴다. Harmony Hall에서 리모컨 ▼로 영사기를 내리고 디스크를 넣는다.
19. **B1 CCTV·B2 운행 제한 해제**: 방재 관제실에서 CCTV 모니터 벽을 조사하면 소등 컷씬이 나온다. 그 뒤 '승강기 제어반' 키를 '해제'로 돌린다. 7F, 13F, 2F를 모두 끝내야 돌아간다.
20. **B2 카메라·외부 회선 차단**:
    - 복도 카메라가 문 쪽을 볼 때 기둥 밑 사각지대에 숨었다가, 카메라가 엘리베이터 쪽으로 돌아가면 서버실로 들어간다.
    - 'CCTV 분배함'에서 전원선을 뽑고, 전력·냉각실 '외부 회선 패널'에서 비상 차단 레버를 내린다.
21. **B2 메인 콘솔 DELETE**: 콘솔에서 DELETE를 누르면 로봇이 깨어난다. 약 16초 안에 '장비 운반 상자'를 밀어 출구 문을 막는다. 이어지는 삭제 배틀에서는 방해가 뜰 때마다 13초 안에 맞는 명령을 입력한다.
    - `kill n`
    - `rm /backup/...`
    - `block n`
    - `resume del-NN`

## 확인하지 못한 부분과 남은 불일치

- 2번 열쇠함과 4번 안내도 생략은 아직 커밋되지 않은 작업 트리 수정이다. 커밋 전에 바뀔 수 있다.
- 옛 흐름을 설명하는 게임 안 문구가 남아 있다. `js/floors/registry.js:35` 태양광 안내문은 블로그 앱 내려받기를 말하고, `js/interaction/inventory.js:19` 백업 장치 설명은 17층 컴퓨터만 말한다.
- 8번 힌트의 출처인 1F 건강관리실 점검표와 Vision Hall 진열장 본문은 `js/floors/floor-01.js` 주석으로만 확인했다.
- 3번, 4번, 7번, 12번 이후의 해법은 이번 재확인에서 코드 변경분만 대조했다. 실제로 플레이해서 확인한 것은 아니다.
