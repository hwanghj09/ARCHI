# 정신력 공포 연출 개편

## 형상과 공간

떠다니는 얼굴 대신 기존 수호의 대기·걷기 그림을 어두운 사람 형상으로 사용한다. 일반 등장과 추격 모두 수호와 같은 192px 칸과 바닥선을 쓴다. 카메라를 따라 화면 가장자리에 붙거나 추격 중 두 배로 커지지 않는다.

형상은 월드 안에서 배경 위, 독립 소품·문과 어둠 막 아래에 그린다. 실제 어둠이 가리고 손전등이 드러낸다. 가구 가장자리와 문틀 옆을 우선해 배치한다. 배경 그림 한 장에 합쳐진 가구는 별도 가림 면이 없으므로 독립 소품처럼 몸을 가릴 수 없다.

## 등장 빈도와 화면

- 새 게임 정신력: 35% → 85%. 기존 저장의 정신력은 유지한다.
- 공격하지 않는 형상: 정신력 30% 미만의 어두운 장소에서 45~90초 간격으로 등장한다. 같은 장소에 머무르는 동안 다시 등장하지 않는다. 표시 시간은 2.8초다.
- 후속 요청으로 자동 얼굴 팝업, 붉은 눈과 파편, 화면 깜빡임, 붉은 비네트, 환각 등장 노이즈·색 변화·화면 흔들림과 기존 효과음을 복구했다.
- 화면 효과는 별도의 `#hallucination-effects`에 그려 월드 형상의 조명·가림과 분리한다. 추격 안내는 아래쪽의 작은 문구를 유지한다.
- 정신력 단계·약·이동 피로·모니터 이상과 배경 긴장 음악을 유지한다.

## 정신력 0% 접근

- 첫 접근까지 45초, 회피 뒤 다음 접근까지 60초를 둔다.
- 화면 안의 여유 공간에서 발소리와 함께 나타나 1.8초 서 있다가 걸어온다. 기존의 강제 손전등 소등, 방향 전환 입력 지연, 지수 가속을 없앴다.
- 접근 속도는 처음 거리 기준 약 3.2초에 닿는 일정한 속도다. 접촉 판정 여유를 포함하면 가만히 있을 때 예고 시작 후 약 4~5초에 잡힌다.
- 접근하는 방향을 350ms 비추거나 충분히 멀어지면 물러난다. 배터리 소진·충전 중에는 공격을 중단한다.
- 안내는 아래쪽의 작고 깜빡이지 않는 문구로 좌우 방향과 F 조작을 알린다. 기존 터치 손전등 버튼도 그대로 쓴다.
- 잡힐 때 기존 전체 화면 얼굴 영상과 전용 효과음을 재생한다. 게임오버 창에서 재개하며 정신력을 최소 50%까지 회복한다.
- 조사·휴대폰·퍼즐·컷씬·엘리베이터·장면 전환·불러오기는 진행 중인 기척을 정리한다.

## 검증

`tests/horror-staging.mjs`는 데스크톱·모바일에서 바닥선, 카메라 이동, 크기 유지, 등장 간격, 예고·회피, 중단 조건과 안내 위치를 검증한다. 데스크톱 화면 픽셀 비교로 어둠·손전등·전경 소품의 실제 가림도 검증한다.

추가 회귀 범위: 정신력·엘리베이터 환각·개발 도구·저장 슬롯·손전등·오디오·스크립트 문법. 전체 게임 완주와 실제 스피커 청감 평가는 포함하지 않는다.

## 환청

정신력 50% 미만의 일반 탐색 중 22~42초 간격으로 없는 사람의 발소리, 문 두드림, 알아듣기 어려운 속삭임 중 하나가 들린다. 직전 종류는 제외하며 수호의 좌우 180~400px 지점에서 나는 것처럼 스테레오 위치와 거리에 따른 음량을 적용한다. 이 소리는 적·문·단서를 실제로 생성하거나 진행 상태를 바꾸지 않는다.

환청은 기존 Web Audio 효과음 경로에서 합성한다. 속삭임은 잡음에 성도 공명을 입힌 소리로, 녹음된 대사나 의미 있는 문장은 없다. 정신력 회복, 메뉴·탭 숨김, 조사·퍼즐·휴대폰·컷씬·층 이동·실제 추격 중에는 중단하고 대기 시간을 다시 센다. 전체 음량·음소거를 따른다. 개발자 모드의 이벤트 창에서 **환청 재생**으로 즉시 확인할 수 있다.

`tests/horror-effects-audio.mjs`가 효과 복구, 합성 파형의 유효성·음량, 좌우 배치, 반복 방지와 중단 조건을 검증한다. 실제 오디오 버퍼를 스테레오로 렌더한 미리듣기는 `.local/horror-effects/auditory-preview.wav`에 저장한다.
