# ARCHI UI 디자인

2026-10-22. 화면을 가리는 큰 원형 버튼과 표면마다 달랐던 색·프레임을 정리하고, 기존 건물·인물·소품 그림에 어울리는 야간 시설물 분위기로 통일했다.

## 참고한 게임

- [Control 메뉴·소지품 화면](https://interfaceingame.com/games/control/): 왼쪽 정렬, 명확한 글자 크기 차이, 선택 항목의 밝은 면과 나머지 항목의 절제된 구분선을 참고했다.
- [Alien: Isolation 제작진 인터뷰](https://blog.playstation.com/2014/03/26/first-look-behind-the-terror-of-alien-isolation/): 화면 정보도 게임 세계의 몰입을 이어야 한다는 설계를 참고했다. HUD는 모서리에 작게 배치하고 휴대폰·종이·설비의 실제 그림을 유지했다.

## 적용

검정·회색 바탕에 아이보리 글자, 황동색 선택 표시를 쓴다. 위험·정신력 상태에는 기존의 색상과 글자 안내를 함께 유지한다. 공통 표현은 `css/interface.css`에서 관리한다.

- 메인 메뉴: 굵은 제목, 선택 행 강조, 정돈된 설정·저장 슬롯·일시정지 화면. 플레이 중 Esc로 연 일시정지 메뉴에서도 설정을 열 수 있고, 뒤로 가기·Esc는 일시정지 메뉴로 돌아간다. 조작키 설정을 거쳐도 같은 경로로 복귀하며 설정 중에도 게임은 멈춘 상태를 유지한다.
- HUD: 위치·목표는 왼쪽 위, 정신력은 왼쪽 아래, 도구는 오른쪽 아래. 버튼에 이름과 현재 조작키를 표시하고 가방에는 실제 소지품 개수를 표시한다.
- 터치 일시정지: 오른쪽 위 버튼으로 기존 일시정지 메뉴를 열 수 있다.
- 가방: 데스크톱 4열·모바일 2열, 읽기 쉬운 물건 이름과 충분한 선택 영역. 소지품이 많으면 내용만 스크롤되고 닫기는 유지된다.
- 조사창·대사: 얇은 프레임과 여백으로 읽기에 집중한다. 종이·사원증·화이트보드 등 실제 그림의 크기·글씨 배치는 보존하며 CCTV 전체 화면은 별도 구성을 유지한다.
- 휴대폰: 차분한 어두운 화면, 선명한 시계·앱·플래시 상태, 정돈된 메모·계산기·사진 앱. 기존 픽셀 아이콘과 기기 그림을 사용한다.
- 지도·도어락·게임 오버: 같은 글자·색·버튼 규칙을 적용한다.

키보드 초점 표시, 동작 줄이기, 화면 낭독기 이름과 상태, 최소 44px 조작 영역을 유지한다. 화면의 조작키 표시는 설정에서 변경한 키를 따른다.

## 검증

`tests/ui-layout.mjs`는 1440×900, 1280×720, 390×844, 844×390, 568×320, 320×568에서 HUD 겹침, 터치 영역, 조작키 표시, 일시정지, 가방 스크롤, 휴대폰 플래시, 긴 조사창을 확인한다.

메뉴·조사창·가방·휴대폰·조작키·지도·아이템 획득·17층 전력 퍼즐·기기 앱 그림·저장 슬롯·글 표면·새 UI 배치 검사 12개와 스크립트 문법 92/92를 통과했다. 글 표면 검사는 실제 조사 데이터 90개를 데스크톱·모바일·가로 화면에서 확인했다.

검사 과정에서 사원증 획득 제목·500ms 플래시 점등 지연·변경된 CCTV 설명에 남아 있던 과거 기대값도 현재 규칙에 맞췄다. 전체 `npm test`, 전체 엔딩 연속 수동 플레이, 실제 모바일 기기는 이번 UI 작업에서 검증하지 않았다.
