# 효과음·공간 환경음 확장 · 2026-10-18

기존 Web Audio 합성 경로에 소리 24종을 추가하고 실제 조작에 연결했다. 기존 전체 음량 설정을 함께 사용한다.

| 구분 | 적용한 소리·위치 |
| --- | --- |
| 이동 | 타일의 단단한 구두 소리, 카펫의 둔탁한 마찰음, 철제 바닥의 짧은 울림, 착지 충격음 |
| 문 | 나무문의 낮은 마찰·닫힘, 금속문의 걸쇠·철컥임, 유리문의 가벼운 잠금·공명, 자동문의 레일·모터 |
| 종이·소지품 | 문서·메모·노트 펼치기와 지도 열기, 가방 지퍼, 개발실 서랍, 서랍의 종이 들어내기 |
| 장치 | 레버 걸쇠, 플러그 체결, 카드 스캔, 열쇠·크랭크·선택기 조작, 버튼 클릭 |
| 컴퓨터·키패드 | 메모 입력과 비밀번호 입력의 짧은 키 타격음, 컴퓨터 버튼 클릭음 |
| 전력 | 태양광 레버·층 전력 공급 전환·17층 비상 회선 연결 성공 시 릴레이 작동음 |
| 공간 | 서버실 냉각 팬, 설비실 전기·배관 저음, 화장실 배관 소리, 넓은 홀의 낮은 공기 울림 |
| 간헐 환경음 | 화장실 세면대에서 들리는 물방울, 설비실 좌우에서 간헐적으로 나는 배관 금속음 |

바닥 재질은 현재 장소에 맞춰 고른다. 복도·화장실·주방은 타일, 사무실·회의실·홀은 카펫, 서버실·설비실·옥상·승강기 안은 금속 계열이다. 문 재질은 기존 문의 스타일과 스프라이트 경로를 사용한다. 방의 배치·이동 속도·애니메이션은 바꾸지 않았다.

발걸음·문·종이·키보드·물방울·배관음은 세 변형 중 직전 소리를 제외해 고른다. 발걸음의 기존 달리기·착지 음량과 재생 간격을 유지한다. 서랍 종이는 실제로 들어냈을 때만 소리가 나고, 가방에서 카드를 읽고 목록으로 돌아올 때는 지퍼를 다시 재생하지 않는다.

월드 좌표가 있는 소리는 플레이어와의 거리에 따라 줄어들고 좌우 위치가 반영된다. 800px 이상 떨어진 소리는 재생하지 않는다. 환경음은 방을 나갈 때 부드럽게 바뀐다. 물방울·배관음은 입장 후 9~18초 뒤 처음 발생하고, 이후 11~24초 간격으로 들린다. 메뉴·다른 탭·컷씬에서는 간헐음을 중지하고, 복귀 시 밀린 소리를 몰아서 재생하지 않는다. 서버실·설비실의 전기 환경음은 해당 층의 전력을 따른다.
