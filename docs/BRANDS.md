# 상표 이름 바꾸기

[`js/core/brands.js`](../js/core/brands.js) 맨 위의 `BRAND_NAMES` 값을 수정하고 게임을 새로고침하세요.

| 설정 | 기본 이름 | 표시 위치 |
| --- | --- | --- |
| `softwareCompany` | ARCHI Soft | 회사명·층별 안내 |
| `databaseCompany` | ARCHI Data | 회사명·층별 안내 |
| `databaseProduct` | ARCHI DB | DB 제품명 |
| `store` | VU | 편의점 간판·영수증·설명 |
| `ramen` | 인라면 | 밀기 상자 앞·옆면·아이템 설명 |
| `ramenEnglish` | IN RAMEN | 상자의 영문 표기 |

예: `store: '우리상점'`, `ramen: '별라면'`으로 바꿀 수 있습니다. 간판과 상자의 글자는 그림과 분리되어 있어 다시 그릴 필요가 없습니다. 작은 간판에서 읽기 쉽도록 짧은 이름을 권장합니다.

그림 자체를 교체하려면 같은 파일의 `BRAND_ART`에서 간판 심볼과 상자 이미지 경로를 수정하세요. 상자 이미지는 글자 없는 투명 PNG를 사용합니다. 충돌 크기와 퍼즐 이동 범위는 층 데이터에서 관리합니다.

`f16-cu` 같은 내부 ID·저장 키·기존 이미지 파일명은 유지됩니다. 이름을 바꿔도 수집 기록과 문 잠금 상태를 이어서 사용할 수 있습니다. 원본 층 데이터의 기존 상표 문자열은 표시할 때 이 설정으로 변환됩니다.

신발·엔딩 신발·사원증·PC 시작 버튼의 실제 로고는 지우고 무상표 또는 자체 도형으로 바꾸었습니다. 플레이어 머리와 기존 투명도 윤곽은 유지했습니다. 과거 참고용 원본/프리뷰는 제작 기록으로 남아 있으며 게임이 사용하는 스프라이트와 구분됩니다.
