# 단면 에셋 커밋 적용 확인

적용 대상: `c872fa507394fbe6d300337048331428ca0cd7a8`.

2~10층 중 7층을 제외한 층의 단면 배경·벽·문·조사 지점을 현재 main에 병합했다. 최근 수정은 먼저 `4ecf1e2`로 보존했으며, 가방 Tab 키·17층 게시판 테두리·정전 가시거리 175px를 유지했다. 원격으로 푸시하지 않았다.

## 병합 보완

- 기존 셔터 연출·문 효과음·조사 글 표면·테두리 처리에 새 문 스프라이트와 그림 속 퍼즐 설비를 연결했다.
- 새 조사 지점의 중복 CSS 테두리를 제거하고, 남은 소품에 맞춰 테두리 측정 데이터를 다시 생성했다.
- 연구 노트와 QA 원본 재현 기록은 기존 노트·서류 조사 화면으로 유지했다.
- 교체되어 사라진 방 ID 18개의 저장을 같은 층 복도로 옮겨 재개한다. 소지품과 진행 기록은 보존하며 잘못된 저장 검증은 유지한다.
- 변경된 방 ID·영사기 필수 물건·공통 충전함·조사창 읽기 방식에 테스트를 맞췄다. README의 해당 층 설명을 현재 배치로 갱신했다.

## 확인 결과

- 엘리베이터 전체 순회 파일을 제외한 회귀 검사 40개 통과. 처음 실패한 효과음·소품 테두리 검사는 수정 후 각각 다시 통과했다.
- 장면 검사에서 스크립트 66개, 장면 94개, CSS 이미지 60개의 파싱·로딩 확인.
- 새 복도와 방 화면 10개를 오류 없이 캡처했고, Harmony Hall·QA 시험실 화면을 시각적으로 확인했다. 이미지와 검사 로그는 `.local/import-*`에 보관한다.
- 엘리베이터 경로 검사는 구간을 나누어 16~5층의 이동·퍼즐을 확인했다. 브라우저의 CSS 좌표 표현과 새 공통 충전함·조사창에 따른 검사 불일치를 수정했다. 4층 이후의 전체 순회 완료까지는 확인하지 않았다.
- 병합 충돌 표시와 Git 공백 오류가 남지 않았는지 확인했다.

실제 브라우저 전체화면 수동 조작과 모든 층의 연속 플레이는 이번 확인에 포함하지 않았다.
