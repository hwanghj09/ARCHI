## 7. 화장실 상호작용

### 현재 구조

- 모든 층의 화장실 내부는 **17층 화장실 하나를 같이 쓴다.** `js/floors/helpers.js`의 `restroomInterior`(폭 1800, 창 없음, 배경 `assets/background/floor17/restroom.png`)를 `js/floors/registry.js`의 `RESTROOMS`가 층마다 `{ id: 'f16-restroom', ...restroomInterior }`로 복사한다. 16층도 문만 전용 그림이고 **안은 17층과 똑같다.**
- 소품과 조사 대상이 없다.
- 배경 그림에 그려진 것 (월드 좌표): 긴 거울 x≈413..912, 세면대 3개 x≈445..876, 종이 타월함 x≈944..1012, 열린 칸 x≈1071..1280, 닫힌 칸 문 x≈1362..1552, 오른쪽 쓰레기통 x≈1629..1711. 출구 x≈185..330(E 힌트 157..358).

### 16층 화장실 조사 요소 제안

그려진 물건 위에 투명 `fixtures`를 얹는다. 청소 점검표만 새로 CSS 종이로 그린다. 15층과 겹치지 않게 **세면대·종이 타월함·청소 점검표**를 쓰고, 이야기는 16층의 키오스크·폐기 스티커와 잇는다.

| 이름 | 위치 | 조사 문구 초안 (정전 상태) |
| --- | --- | --- |
| 세면대 | x=445, width=431 | 센서식 수도꼭지에 손을 대 보지만 물이 나오지 않는다. 배수구 옆에 CU 삼각김밥 포장지가 젖은 채 붙어 있다. "새벽 전원 차단 · 폐기" 스티커가 그대로다. |
| 종이 타월함 | x=944, width=68 | 종이 타월 맨 아래 한 장에 볼펜 낙서가 있다: "카페 키오스크가 내 이름 불렀음. 등록한 적 없는데." 날짜는 사흘 전 새벽이다. |
| 청소 점검표 | x=1720, width=44 (새 CSS 종이) | 야간 미화 점검표. 새벽 칸 서명이 3주 전에서 끊겼다. 마지막 칸 옆 메모: "키오스크가 먼저 말 걸어서 무서움. 야간 근무 그만둡니다." 그 뒤로는 "야간 미화 중단 · 순찰 로봇 대체" 도장뿐이다. |

스토리 연결: 청소 점검표는 카페 커피 바 메모("새벽 청소 여사님 말로는 키오스크가 먼저 인사했대")와 3층 청소 카트("야간 미화 중단, 대신 로봇 순찰")를 잇는다. 종이 타월 낙서는 고객의 소리 게시판(키오스크가 습관을 다 앎)과 14층의 행동 관찰 복선으로 이어진다. 초자연 현상이 아니라 **ARCHI가 사람을 알아보기 시작했다**는 공포다.

### 층마다 문구를 다르게 하려면

`registry.js`의 `RESTROOMS`가 층 설정의 화장실 항목을 합치도록 바꾼다. 예: `{ id, ...restroomInterior, ...(FLOOR_LAYOUTS[floor]?.restroom || {}) }`로 두고, `FLOOR16_LAYOUT`에 `restroom: { fixtures: [...] }`를 적는다. 화장실 배경이 `data-art`로 그려지므로 fixture는 투명하게 두고, `tests/floor16-art.mjs`의 화장실 내부 검사도 함께 확인한다.

## 8. 조사 UI 대상

조사 결과는 화면 하단 대화창에 보이고, 아래처럼 글자를 읽는 단서는 그 물건 모습 그대로 크게 펼쳐진다. 2026-10-02에 구현했다(`js/interaction/writing.js`·`writing.css`, 소품의 `surface`·`look`·`writing`·`caption`). UI 종류는 `board` → 화이트보드·게시판·칠판, `document` → 서류(`document`), `screen` → 화면(`screen`), `note` → 메모(`memo`) 또는 서류 위 손글씨로 옮겼고, ✎는 손글씨(`hand`), **캡션**은 `caption`이다. 이 표가 그 배치의 기준이다. 카페 테이블은 `image`로 조현아 사원증 그림을 그대로 보여 준다. CU 셔터 잠김 문구는 위 제외 목록대로 대화창이다.

UI 종류: `note`(포스트잇·메모) · `board`(게시판·보드) · `document`(문서·출력물) · `screen`(화면). 내용은 지금 `message` 문구를 그대로 쓰되 종이에 적힌 부분과 서술을 나눴다. **캡션**은 UI 위·아래의 작은 서술, **✎**는 손글씨다.
