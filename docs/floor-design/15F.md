## 7. 화장실 상호작용

### 현재 구조

- 모든 층의 화장실 내부는 **17층 화장실 하나를 같이 쓴다.** `js/floors/helpers.js`의 `restroomInterior`(폭 1800, 창 없음, 배경 `assets/background/floor17/restroom.png`)를 `js/floors/registry.js`의 `RESTROOMS`가 층마다 `{ id: 'f15-restroom', ...restroomInterior }`로 복사한다. 17층만 `js/floors/floor-17.js`에서 따로 같은 값을 쓴다.
- 소품과 조사 대상이 **하나도 없다.** 층마다 달라지는 것은 헤더 문구(`15F · 화장실`)뿐이다.
- 배경 그림에 그려진 것 (월드 좌표, 원본 1983px → 1800px 환산): 긴 거울 x≈413..912, 세면대 3개 x≈445..876, 종이 타월함 x≈944..1012, 쓰레기통 x≈935..1021, 열린 칸 x≈1071..1280, **닫힌 칸 문 x≈1362..1552**, 오른쪽 쓰레기통 x≈1629..1711. 출구는 x≈185..330(E 힌트 157..358)이다.

### 15층 화장실 조사 요소 제안

그려진 물건 위에 투명한 `fixtures`(그림 없이 조사 영역만)를 얹는 방식이다. 청소 점검표만 그림에 없어서 작은 종이 한 장을 CSS로 그린다.

| 이름 | 위치 | 조사 문구 초안 (정전 상태) |
| --- | --- | --- |
| 거울 | x=413, width=499 | 어둠 속 거울에 비친 얼굴이 낯설 만큼 지쳐 보인다. 거울 위 모서리에 손톱만 한 검은 센서가 붙어 있다. 라벨: "재실 감지 · 시설 자동화 연동". 이 층에 몇 명이 남았는지 누군가는 세고 있다. |
| 닫힌 칸 | x=1362, width=190 | 맨 끝 칸이 안에서 잠겨 있다. 잠금 표시는 붉은 "사용 중". 두드려도 대답이 없고, 문 아래 틈으로는 아무것도 보이지 않는다. 잠금 장치 옆 스티커: "원격 잠금 시범 설치 · SYSTEM". |
| 청소 점검표 | x=1720, width=44 (새 CSS 종이) | 청소 점검표. 낮 칸에는 미화원 서명이 이어지는데, 새벽 칸에는 지난달부터 같은 도장만 찍혀 있다: "순찰 확인 · 로봇 03:10". 로봇은 걸레를 들 수 없다. |

스토리 연결: 재실 감지 센서는 8층 "관찰실 재실 인원 집계", 3층 "남은 인원 질문"과 이어진다. 원격 잠금은 ARCHI의 건물 통제 수단(자동문)과, 순찰 도장은 3층 "야간 미화 중단, 대신 로봇 순찰"과 맞는다. 유령이 아니라 **시스템이 사람을 세고 있다**는 공포로 기획.md와 어긋나지 않는다.

### 층마다 문구를 다르게 하려면

`registry.js`의 `RESTROOMS`가 층 설정의 화장실 항목을 합치도록 바꾼다. 예: `{ id, ...restroomInterior, ...(FLOOR_LAYOUTS[floor]?.restroom || {}) }`로 두고, 각 층 파일에 `restroom: { fixtures: [...] }`를 적는다. 17층은 `floor-17.js`에서 같은 방식으로 추가하고, 화장실을 방문하는 `tests/elevator.mjs`의 `visitRestroom` 검사도 함께 확인한다.

## 8. 조사 UI 대상

조사 결과는 화면 하단 대화창에 보이고, 아래처럼 글자를 읽는 단서는 그 물건 모습 그대로 크게 펼쳐진다. 2026-10-02에 구현했다(`js/interaction/writing.js`·`writing.css`, 소품의 `surface`·`look`·`writing`·`caption`). UI 종류는 `board` → 화이트보드·게시판·칠판, `document` → 서류(`document`), `screen` → 화면(`screen`), `note` → 메모(`memo`) 또는 서류 위 손글씨로 옮겼고, ✎는 손글씨(`hand`), **캡션**은 `caption`이다. 이 표가 그 배치의 기준이다.

UI 종류: `note`(포스트잇·메모) · `board`(게시판·보드) · `document`(문서·출력물) · `screen`(화면). 내용은 지금 `message` 문구를 그대로 쓰되, 종이에 적힌 부분과 서술 부분을 나눴다. **캡션**은 UI 위나 아래에 작게 두는 서술이고, **✎**는 손글씨다.
