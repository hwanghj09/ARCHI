# 개발·시연 단축키

| 키 | 게임 안에서 하는 일 |
|---|---|
| **F2** | 개발 도구 사이드바를 켜고 끈다. 층·방 이동, 퍼즐 건너뛰기, **퍼즐 열기**(퍼즐 23개 목록), 정신력·배터리 조절, 아이템 획득, 이벤트 실행을 할 수 있다. |
| **F3** | 17층 관리자실로 가서 **비상 전력 분배반 전선 연결** 화면(S→R→E)을 연다. 회로 안내도는 관리실 책상에서 다시 볼 수 있다. |
| **F4** | 1층 로비로 가서 **ARCHI 포스터** 확대 화면을 연다. QR을 휴대폰으로 찍으면 소개 페이지(SSH 정보)가 열린다. |
| **F5** | 12층 모델 평가실로 가서 **야간 로그 단말기**를 연다. 약 2초 뒤 기록 삭제가 시작되므로, 단말기를 닫고 옆 네트워크 랙에서 LAN 케이블을 뽑는다. 그 뒤 다시 단말기에서 `find`·`grep`·`cat`으로 기록을 찾는다. |

F3·F4·F5와 F2의 퍼즐 열기는 그 퍼즐 바로 앞까지 진행된 상태(아이템·전력 포함)로 바꾼 뒤 퍼즐 화면만 띄운다. 퍼즐은 발표자가 직접 푼다.

- 조사창이나 키패드처럼 다른 창이 열려 있으면 동작하지 않는다. Esc로 닫고 누른다.
- 진행 상태가 바뀌고 자동 저장에 반영된다. 시연용 세이브는 따로 쓰는 것이 좋다.
- 게임 화면에서 F5를 눌러도 브라우저가 새로고침되지 않는다. 새로고침은 Ctrl+R로 한다.
