# 옥상 → 17층 조명 복구 연출

정전 이후 옥상에서 태양광 전력을 처음 17층에 공급하면 재생한다. 옥상 분배반과 휴대폰 태양광 앱 모두 같은 공급 함수를 사용한다. 다른 층 공급, 공급 해제, 옥상 밖의 원격 조작, 저장 복원 중에는 시작하지 않는다.

약 4.7초 동안 옥상에서 페이드아웃 → 어두운 17층 복도 → 불규칙한 전등 깜빡임 → 켜진 복도를 보여 주기 → 옥상 복귀 순서로 진행한다. 기존 17층의 점등·소등 배경과 문을 별도 카메라 화면에 표시한다. 실제 플레이어·물리 월드·위치는 옥상에 유지하며, 승강기 UPS 전력은 바꾸지 않는다.

연출 중 조작·지도·메뉴와 정신력 진행을 막고, 충전기에 둔 휴대폰 충전은 계속한다. 숨긴 탭에서는 기존 고정 게임 시계와 함께 멈춘다. 움직임 줄이기 설정에서는 카메라 이동과 반복 깜빡임을 빼고 한 번에 켠다.

Esc, 건너뛰기 버튼 또는 해당 버튼에서 Enter로 종료해도 17층 공급을 유지한다. 완료 기록 `story-solar-17-seen`을 기존 저장 형식에 남겨 반복하지 않으며, 복원 중에는 미완료 연출을 정리한다. 이미지 로딩 실패 시에도 입력 잠금을 풀고 공급 결과는 유지한다.

## 주요 파일

- `js/scene/solar-restore-scene.js`, `css/solar-restore-scene.css`: 화면·카메라·조명·진행·종료 처리.
- `js/interaction/power.js`: 옥상에서 첫 17층 공급 시 시작.
- `js/core/loop.js`, `js/core/state.js`: 고정 시계와 실행 상태.
- `js/input/keyboard.js`, `js/ui/map.js`, `js/ui/main-menu.js`: 연출 중 입력 제한과 건너뛰기.
- `js/core/save.js`: 저장 복원 시 화면과 입력 잠금 정리.
- `index.html`: 연출 화면과 파일 등록.

## 검증

- `node tests/solar-restore-scene.mjs`: 분배반·휴대폰 앱 진입, 암전·깜빡임·점등, 실제 옥상 위치 유지, 조작 잠금, 원래 위치 저장, 최초 재생 기록, 17층 실제 점등, 단계별 건너뛰기, 모바일, 움직임 줄이기, 저장 복원, 잘못된 공급 조건, 이미지 실패 복구를 검사한다.
- `node tests/solar-app.mjs`: 기존 앱 다운로드·전송·원격 공급 흐름 통과.
- `node tests/script-syntax.mjs`: 91개 스크립트 파싱 통과.
- 기존 `tests/background-power.mjs`는 현재 UI에서 숨긴 `#floor17-lights`를 클릭하려다 중단된다. 이 작업에서는 해당 스위치나 테스트를 변경하지 않았다. 새 검사에서는 복귀 후 17층에 직접 가서 점등 상태와 실제 배경 경로를 확인한다.
- 전체 `npm test`는 실행하지 않았다.
