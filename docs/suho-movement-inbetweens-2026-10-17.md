# 수호 이동 중간 프레임 · 2026-10-17

걷기를 6→12프레임, 달리기를 8→16프레임으로 늘렸다. 일반 이동과 휴대폰 OFF/ON을 합해 새 자세 42장을 추가했다. 기존 셀은 픽셀 그대로 보존하고 각 셀 뒤에 새 자세를 삽입했다. 256×256 투명 셀, 이동 속도와 한 주기 이동 거리는 유지했다.

관절의 연결, 체중을 받는 무릎, 반대 다리의 회수, 발끝 밀기, 공중에서 발 내밀기와 반대 팔의 위상을 기준으로 그림을 검토·수정했다. 걷기의 과도한 전방 기울기, 달리기 반주기의 팔 앞뒤, 휴대폰 먼쪽 팔의 가림 관계를 보정했다. 새 그림의 크기·머리 기준점·발 높이를 정렬했고, 휴대폰 LED 좌표와 점프/낙하 재사용 인덱스도 새 시트에 맞췄다.

기존 `movement.mjs`의 새 12프레임 검사는 통과했으며 이후 195행의 엘리베이터 호출 표시 기대값에서 실패했다. 기존 `running.mjs`의 새 16프레임·속도·점프 검사는 통과했으며 이후 99행의 맵 끝 충돌 기대값에서 실패했다. `blackout-scene.mjs`는 81행의 상태 검사에서 실패했다.

세 실패 모두 변경 전 `dc9c99c`의 HTML·JS·CSS·원래 테스트를 별도 복사해 같은 Chromium에서 실행했을 때 동일한 행에서 재현됐다. 이 작업에서는 해당 동작을 변경하지 않았다. 전체 `npm test`는 실행하지 않았다.
