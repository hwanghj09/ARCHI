# 수호 이동 스프라이트 · 2026-10-18 수정

걷기의 상체 기울기·셔츠 주름·체형이 기존 그림과 번갈아 바뀌던 문제를 수정했다. 기존 12프레임 조합을 제거하고 접지·하강·통과·발끝 밀기를 양발로 반복하는 **8프레임 걷기**로 다시 구성했다. 일반·휴대폰 OFF·플래시 ON 걷기를 같은 단계로 맞추고 머리 기준점·몸 크기·발 높이를 정렬했다. 달리기는 기존 8프레임 사이에 중간 자세를 넣은 16프레임을 유지한다.

**플래시 ON 상태에서는 달릴 수 없다.** Shift를 눌러도 걷기 속도와 걷기 그림을 유지한다. 켜진 달리기 확장 시트와 해당 미리보기는 제거했다. 점프·낙하에서는 기존 공중 자세 두 장만 추출한 `jeong-suho-phone-jump-on.png`를 사용한다.

휴대폰은 먼쪽 손으로 잡고 가까운 빈손 팔이 어깨부터 손목까지 보이도록 다시 그렸다. 빈손은 뒤쪽(0/1/7번) → 중간(2/6번) → 앞쪽(3/4/5번)을 오가며 다리와 반대로 흔들린다. 팔이 겹쳐 붙어 보이던 부분을 정리하고, ON에는 생성된 LED 부분만 OFF에 합성해 몸과 팔을 동일하게 유지했다.

마지막 프레임을 포함한 3/7번의 높은 무릎 들기도 낮췄다. 뒤쪽 발끝이 지면을 지지하는 동안 앞발은 지면 가까이 내밀며, 일반·휴대폰 OFF·플래시 ON에 모두 적용했다.

일반 걷기의 6개 자세에서 뒤통수와 목 사이에 남아 있던 회색 삼각형 잔상도 제거했다. 생성 도구로 정리한 투명 영역을 원본에 적용해 잔상 픽셀만 지웠으며, 나머지 원본 그림은 보존했다. 밝은 배경·어두운 배경에서 머리 외곽을 확대 확인했다.

걷기 속도는 200px/s, 한 주기는 184px(0.92초)이며 달리기는 340px/s, 192px(약 0.565초)로 유지했다. 원본 6프레임 걷기 파일은 제작 기록으로 보존한다. 런타임에서는 새 그림을 혼합 없이 사용한다.
