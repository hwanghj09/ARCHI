# 수호 이동 스프라이트 · 2026-10-18 수정

수호 걷기에서 머리가 커졌다 줄어들고 회색 잔상이 남던 문제를 수정했다. 일반·휴대폰 OFF·플래시 ON의 **8프레임 걷기** 모두에 같은 56×56 머리·목·옷깃 레이어를 몸 정규화 후 합성한다. 머리는 확대·축소 없이 상하 3px 이내로만 이동한다. 접지·하강·통과·발끝 밀기를 양발로 반복하며, 달리기는 기존 8프레임 사이에 중간 자세를 넣은 16프레임이다.

**후속 변경(2026-10-20): 플래시 ON에서도 달릴 수 있다.** 새 16프레임 ON 시트와 프레임별 광원 좌표를 적용했다. 제작·재생성은 [휴대폰 스프라이트 기록](../assets/player/phone-movement-source/PROMPTS.md)을 참고한다. 아래의 과거 달리기 차단 검증은 당시 결과다. 당시에는 켜진 달리기 확장 시트와 미리보기를 제거했으나, 후속 요청으로 위의 새 시트를 추가했다. 점프·낙하에서는 기존 공중 자세 두 장만 추출한 `jeong-suho-phone-jump-on.png`를 사용한다.

휴대폰은 먼쪽 손으로 잡고 가까운 빈손 팔이 어깨부터 손목까지 보이도록 다시 그렸다. 빈손은 뒤쪽(0/1/7번) → 중간(2/6번) → 앞쪽(3/4/5번)을 오가며 다리와 반대로 흔들린다. 팔이 겹쳐 붙어 보이던 부분을 정리하고, ON에는 생성된 LED 부분만 OFF에 합성해 몸과 팔을 동일하게 유지했다.

마지막 프레임을 포함한 3/7번의 높은 무릎 들기도 낮췄다. 뒤쪽 발끝이 지면을 지지하는 동안 앞발은 지면 가까이 내밀며, 일반·휴대폰 OFF·플래시 ON에 모두 적용했다.

기존 머리를 어깨·옷깃 경계까지 제거해 회색 목뒤 잔상과 턱 조각이 겹치지 않게 했다. 밝은 배경·어두운 배경에서 외곽을 확대 확인했다. 정렬한 머리 픽셀의 해시는 이전 16종에서 1종으로 통일됐으며, 24개 자세가 모두 동일하다. y=96 아래의 팔·다리 등 기존 그림은 변경 전과 픽셀 단위로 같다.
