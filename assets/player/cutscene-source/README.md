# 수호 컷씬 전용 스프라이트 · 2026-10-18

내장 `image_gen`으로 기존 수호 원화와 대기 시트를 참조해 컷씬 전용 자세를 새로 제작했다. 생성 프롬프트는 [PROMPTS.md](PROMPTS.md)에 보관한다.

| 원본 | 배열 | 게임 시트 프레임 | 용도 |
| --- | --- | --- | --- |
| reactions.png | 3열 × 2행 | 0 경계, 1 놀람, 2 올려다보기, 3 뒤돌아보기, 4–5 숨 고르기 | 정전, CCTV, 1층 추격 |
| dialogue.png | 2열 × 2행 | 6 생각, 7 불안, 8 안도, 9 사원증 확인 | 정전 독백, 추격 후, 항불안제 후, 출입증과 야간 로그 독백 |

`node scripts/prepare-cutscene-poses.mjs`로 `../jeong-suho-cutscene.png`(2560×256, 256px 셀 10장)를 재생성한다. 각 원본 시트 전체에 같은 배율을 적용해 몸을 숙인 자세의 머리·몸이 확대되지 않게 하고, 최근접 보간과 이진 알파로 외곽을 정리한다. 발바닥은 y=237에 정렬한다.

`showCutscenePose`는 기존 플레이어와 같은 75% 배율로 한 셀만 표시한다. 숨 고르기만 480ms 간격으로 4·5번을 교대한다. 걷기와 달리기에는 기존 이동 애니메이션을 유지하며, 대사·반응 구간에서만 장면별 전용 자세를 사용한다. 공중에서 독백이 시작되면 착지 후 자세를 바꾼다. 이미지 로딩이 실패하면 기존 스프라이트를 계속 표시하고, 종료·건너뛰기 시 일반 애니메이션으로 돌아간다.

오프닝의 앉기·컴퓨터 종료·일어서기, 엘리베이터 버튼 누르기, B2 포획 엔딩은 이미 전용 원화가 있어 해당 그림을 유지했다. 정전 놀람에 쓰던 포획 스프라이트와 CCTV·감정 독백에서 쓰던 평상시 대기 자세를 교체했다.

검증: `node tests/cutscene-poses.mjs`. 자세별·좌우 방향 게임 캡처는 `.local/cutscene-*.png`에 생성한다.

## 검증 결과

- `tests/cutscene-poses.mjs`: 통과. 실제 1층 추격 → 엘리베이터 탈출 → 숨 고르기, 모든 독백의 자세, 정전·CCTV 두 컷씬의 반응, 숨 고르기 2프레임, 이동·착지, 좌우 반전, 건너뛰기·종료, 이미지 실패 복구, 모바일 표시를 확인했다.
- `tests/opening.mjs`, `tests/movement-inbetweens.mjs`: 통과. 오프닝과 일반 이동을 유지했다.
- `tests/script-syntax.mjs`: 90/90 통과. `git diff --check`: 통과.
- 기존 `tests/cctv-scene.mjs`는 관제실 밝기를 `brightness(.6)`으로 기대하지만 현재 배경은 `brightness(1)`이라 실패한다. 컷씬의 새 자세 검사는 별도 테스트에서 통과했다.
- 기존 `tests/blackout-scene.mjs`는 정전 직후 입력 잠금이 해제된다고 기대하지만, 직후 독백이 이어져 `stage.inert`가 참이므로 실패한다. 새 테스트는 이어지는 독백과 그 종료까지 확인한다.
- 기존 `tests/antianxiety-animation.mjs`는 테스트 컨텍스트에 `MANAGER_MEMO_TEXT`가 없어 인벤토리 로딩에서 실패한다. 해당 인벤토리·테스트 준비 코드는 이 작업에서 변경하지 않았다.
- 전체 `npm test`는 실행하지 않았다.
