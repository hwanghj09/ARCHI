# 11층 배경 생성

저장소 루트에서 `python -B assets/background/floor11/build.py`로 재생성한다(Pillow·numpy 필요).

- 원본 단면 그림이 없는 층이므로 공용 `wall/wall-concrete.png` 패널 질감을 남색으로 마감하고 금색 몰딩과 하부 패널을 덧댄다. 영업실은 창, 전략회의실은 꺼진 대형 스크린, 자료실은 창 없는 벽이다.
- `cutaway_finish.py`로 각 방의 천장(높이 100, top 0), 바닥(204, top 556), 벽(475, top 100)을 만든다. 벽 아래 19px은 투명하게 비워 별도 바닥과 겹친다. 전체 배경은 y=0..760을 빈틈없이 덮는다.
- 실내 폭은 영업실 3600, 전략회의실·자료실 1800이다. 기존 floor-kit 소품과 조사 지점, 모니터 환각, 출입문 위치는 유지한다.
- `walls-layout.json`과 공용 벽 모듈로 5000×760 복도를 만든다. 영업실은 혼합 유리, 전략회의실은 간유리, 자료실은 불투명 벽이다. `behind-sales.png`는 같은 실내 벽과 기존 소품의 축소 조합이다.
- 11층 고유 문 그림은 그대로 사용한다. 화장실 문·이름표는 앞선 층과 같은 공용 그림과 위치를 쓴다. 기존 CSS 전면은 배경을 가리지 않도록 숨긴다.
- 방화셔터의 좌표·충돌·그림·애니메이션, 수동 개방 핸들 획득과 영구 개방 상태는 바꾸지 않는다.

`tests/elevator.mjs`의 11층 경로는 새 배경의 크기·레이어와 모든 방 출입·단서·핸들 획득·셔터 차단 및 개방을 검사한다.
