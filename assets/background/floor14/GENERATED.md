# 14층 배경 생성

저장소 루트에서 `python -B assets/background/floor14/build.py`로 재생성한다(Pillow·numpy 필요).

- 공용 `wall/wall-concrete.png` 패널을 남색으로 마감한다. 자료실은 창 없는 적층 패널, 데이터실은 넓은 창, 사용자 실험실은 반사 유리를 쓴다. 기존 개별 소품은 조사 지점과 함께 유지한다.
- `cutaway_finish.py`로 각 방의 천장(높이 100, top 0), 바닥(204, top 556), 벽(475, top 100)을 만든다. 벽 아래 19px은 투명하게 비워 별도 바닥과 겹친다. 합성 배경은 y=0..760을 불투명하게 덮는다.

| 방 | 내부 폭 | 복도 전면 x / 폭 | 복도 벽 |
| --- | --- | --- | --- |
| 연구 자료실 | 1800 | 64 / 480 | 불투명 벽 |
| 데이터 연구실 | 2400 | 560 / 640 | 혼합 유리 |
| 사용자 실험실 | 2100 | 1216 / 560 | 간유리 |

- `walls-layout.json`과 공용 벽 모듈로 `walls.png`(5000×760)를 만든다. 데이터실의 `behind-data.png`는 같은 실내 벽과 기존 데이터 작업대의 축소 조합이다. 중앙 전시장과 오른쪽 휴게 공간의 소품은 유지한다.
- 14층 고유 문과 크기·좌표, 실험 중 표시를 유지한다. 이름표는 공용 천장 띠 아래 y=90에 놓고 화장실 이름표를 문 위 중앙으로 맞춘다. 화장실 문은 16층 그림을 재사용한다.
- 자료실의 `dark`·`litBy: f14-archive-lamp`, 노트·보관함의 `darkMessage`, 작업등 상태 스프라이트는 바꾸지 않는다. 작업등은 어둠을 없애고 재입장 후에도 켜져 있다. 라벨링 현황판의 두 번째 그림(`spriteFrame: 1`)도 유지한다.
- `build.py`는 벽 크기와 불투명도를 자체 검사한다. `tests/elevator.mjs`의 14층 경로는 배경 크기·레이어·이름표·방 출입·단서와 작업등 전후 및 재입장 상태를 검사한다. `tests/interaction-sprites.mjs`는 작업등·라벨링 현황판의 상태와 그림을 검사한다.
