# 15층 배경 생성

저장소 루트에서 `python -B assets/background/floor15/build.py`로 재생성한다(Pillow·numpy 필요).

- 공용 `wall/wall-concrete.png` 패널을 청록색으로 마감한다. 연구실과 세미나실은 창, 본부장실은 블라인드와 목재 하부 패널을 쓴다. 연구실 창은 기존 출구(x=1003) 주변을 비운다.
- `cutaway_finish.py`로 각 방의 천장(높이 100, top 0), 바닥(204, top 556), 벽(475, top 100)을 만든다. 벽 아래 19px은 투명하게 비워 별도 바닥과 겹친다. 합성 배경은 y=0..760을 불투명하게 덮는다.

| 방 | 내부 폭 | 복도 전면 x / 폭 | 복도 벽 |
| --- | --- | --- | --- |
| 연구실 | 3440 | 64 / 860 | 혼합 유리 |
| 세미나실 | 2480 | 954 / 620 | 간유리 |
| 연구본부장실 | 1824 | 3092 / 456 | 불투명 벽 |

- `walls-layout.json`과 공용 벽 모듈로 `walls.png`(5000×760)를 만든다. 연구실의 `behind-lab.png`는 같은 실내 벽과 기존 연구 작업대의 축소 조합이다. 오른쪽 휴게 공간과 연구본부 소식지, 모든 개별 소품·단서는 유지한다.
- 15층 고유 문과 크기·좌표를 유지한다. 이름표는 공용 천장 띠 아래 y=90에 놓고 화장실 이름표를 문 위 중앙으로 맞춘다. 화장실 문은 16층 그림을 재사용한다.
- 세미나실 GPU 상자 충돌체는 기존 x=760, 폭 110, 높이 50과 x=1360, 폭 90, 높이 60을 유지한다. 기존 `gpu-shipping-crate.png`를 그대로 사용하며 배경에 상자를 추가하지 않는다. 두 상자를 넘어 작업 지시서를 조사한 뒤 반대 방향으로 돌아오는 경로도 유지한다.
- `build.py`는 벽 크기와 불투명도를 자체 검사한다. `tests/elevator.mjs`의 15층 경로는 배경 크기·레이어·이름표·방 출입·단서·상자 보행 차단 및 왕복 점프를 검사한다. `tests/object-layout.mjs`는 기존 소품과 조사 영역의 배치를 검사한다.
