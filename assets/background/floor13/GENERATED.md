# 13층 배경 생성

저장소 루트에서 `python -B assets/background/floor13/build.py`로 재생성한다(Pillow·numpy 필요).

- 공용 `wall/wall-concrete.png` 패널을 강철색으로 마감하고 주황 몰딩을 넣는다. 기존 개별 floor-kit 소품은 배경에 합치지 않고 조사 지점과 함께 유지한다.
- 상황실은 꺼진 모니터 벽, 장비 검증실은 창 없는 볼트 패널, 교육장은 높은 띠창이다. 상황실 모니터 벽은 중앙 출구(x=1231, 폭 160) 주변을 비워 문을 가리지 않는다.
- `cutaway_finish.py`로 방별 천장(높이 100, top 0), 바닥(204, top 556), 벽(475, top 100)을 만든다. 벽 아래 19px은 투명하게 비워 별도 바닥과 겹친다. 합성 배경은 y=0..760을 불투명하게 덮는다.

| 방 | 내부 폭 | 복도 전면 x / 폭 | 복도 벽 |
| --- | --- | --- | --- |
| 기술지원 상황실 | 2622 | 3090 / 460 | 혼합 유리 |
| 장비 검증실 | 1824 | 4290 / 320 | 불투명 벽 |
| 고객 교육장 | 1824 | 4620 / 320 | 간유리 |

- `walls-layout.json`과 공용 벽 모듈로 `walls.png`(5000×760)를 만든다. 상황실의 `behind-ops.png`는 같은 모니터 벽과 기존 업무 책상의 축소 조합이다. 복도 왼쪽은 별도 방 없이 기존 공용 업무석을 유지한다.
- 13층 고유 문 그림과 크기·좌표, 고전압·교육 중 표시를 유지한다. 방 이름표는 공용 천장 띠 아래 y=90, 화장실 이름표는 문 위 중앙에 놓고 16층 화장실 문 그림을 재사용한다.
- 상황실 프린터의 `requires: f13-ups`, 검증실 UPS의 `gives: f13-ups`, 상태 스프라이트와 프린터 애니메이션은 바꾸지 않는다.
- `build.py`는 벽의 크기와 불투명도를 자체 검사한다. `tests/elevator.mjs`의 13층 경로는 배경 크기·레이어·이름표·공용 업무석·방 출입·단서와 UPS 전후 프린터 동작을 검사한다. `tests/interaction-sprites.mjs`는 UPS·프린터 상태와 재입장·애니메이션을 검사한다.
