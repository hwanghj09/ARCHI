# 직접 조작 장치 스프라이트

생성: 내장 `image_gen`, 투명 배경. 참고 이미지: `assets/objects/floor-kit/elevator-control-panel.png`.
원본 5장은 `source/`에 보존한다. 실행용 19개 부품은 `node scripts/prepare-manual-control.mjs`로 분할·규격화한다.

## 공통 생성 지시

정면 직교 시점의 2D 산업 시설 공포 게임 소품. 기존 제어반과 같은 세밀한 픽셀/페인팅 질감,
낡은 회색 금속, 작은 흠집, 또렷한 어두운 외곽선. 실제 투명 RGBA 배경. 부품은 서로 겹치지 않고
각 셀 안에 완전히 들어가며 주변에 투명 여백을 둔다. 손·인물·배경·읽을 수 있는 글자·격자선은 넣지 않는다.
고정 바탕판과 움직이는 손잡이는 반드시 분리한다.

## 적용

`css/manual-control.css`가 바탕판과 이동 부품을 겹친다. 기존 `manual-control.js`의 `--p`와 `--angle`을
사용해 레버·스위치·키·크랭크·시계·선택기·버튼·플러그·카드가 입력에 따라 움직인다.
영사기 NAS는 CD, 방화셔터 핸들 삽입은 금속 핸들 이미지로 표시한다. 완료 조건과 수집·전력·문 개방 로직은 그대로 사용한다.
한글 안내, 장치 명칭, 선택지, 버튼 글자는 HTML로 표시한다.

검증: `node tests/manual-control.mjs`, `node tests/manual-control-art.mjs`.
