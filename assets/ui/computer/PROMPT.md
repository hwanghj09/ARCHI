# Computer wallpaper

- Tool: built-in image_gen.
- File: wallpaper.png. Desktop background for the interactive 17F office PC.

## Prompt

Create a wide 3:2 pixel-art desktop wallpaper bitmap for an ordinary office computer in ARCHI, a Korean 2D office mystery game. Peaceful emerald green mountains and a clear lake, pale blue sky with a few small crisp clouds, forested shoreline, quiet soft daylight. Detailed deliberate pixel clusters, restrained natural greens with blue water and light sky. Clean composition with low-detail darker forest at the left edge to place desktop icons and open sky across the top. This is ONLY the landscape wallpaper itself filling the canvas edge to edge, NOT a computer or monitor, no border or frame. No people, animals, text, letters, numbers, icons, windows, UI, symbols, logos, gradients or watermark. Opaque background.
