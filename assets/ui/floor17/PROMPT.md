# 17층 관리실 비상 전력 퍼즐

내장 `image_gen`으로 제작했다. 원본은 `source/`에 보존한다.

## 비상 전력 분배반

참고: `assets/ui/wire-puzzle/wire-panel.png`. 정면 직교 시점, 기존의 낡은 금속·나사·주의 무늬와 세밀한 픽셀/페인팅 질감을 유지한다.
두 칸의 동일한 열린 배전반을 가로로 배치한다. 왼쪽은 빨간 미연결 표시등, 오른쪽은 초록 통전 표시등이다.
양쪽에 단자 네 개씩, 중앙은 게임에서 케이블을 그릴 수 있도록 비운다. 불꽃·손·읽을 수 있는 글자는 넣지 않는다.
상단·하단에는 HTML 제목과 상태를 표시할 빈 명판을 둔다. 바깥은 실제 투명 RGBA다.

`source/emergency-panel.png`의 두 칸을 동일한 480×626으로 규격화해 `emergency-panel-states.png`(960×626)로 저장했다.
관리실 소품은 두 상태를 모두 사용하고, 조작 UI는 첫 칸 위에 단자·연결선을 겹친다.

## 소화전 메모

낡고 접힌 상아색 관리 메모 한 장, 작은 종이 클립, 종이 접힘과 연필 자국. 정면 직교 시점의 기존 소품 화풍.
중앙은 비워 두고 숫자·읽을 수 있는 문구·손·소화전·열쇠는 그리지 않는다. 실제 투명 배경과 충분한 여백.
`source/manager-memo.png`를 여백 제거 후 256×256 투명 캔버스로 규격화했다.
암호와 안내문은 HTML과 `MANAGER_ROOM_CODE`로 표시해 이미지와 게임의 비밀번호가 어긋나지 않게 한다.
소화전과 가방에서 메모를 펼치면 이 종이 이미지를 배경으로 암호와 안내문이 종이 위에 직접 표시된다.

## 적용 및 난도

- 관리실 폭: 1040px. 복도에서 실제 키패드로 열고 드나드는 작은 방이다.
- 태양광: 한 층의 조명만 공급. 관리실 비상 UPS: 승강기·컴퓨터·충전 설비를 별도로 공급한다.
- 안내도: 공급 S→중계 릴레이 R, 중계 R→승강기 E의 두 표를 함께 읽어 최종 연결을 추론한다.
- 오른쪽 단자는 색으로 정답을 노출하지 않는다. 오접속도 그대로 남으며 공급 단자를 눌러 해제한다.
- 네 가닥을 연결한 뒤 회로 검사를 눌러야 한다. 접지나 구동·제어 경로가 틀리면 통전되지 않는다.
- 조작은 마우스·실제 터치 드래그, 두 단자 클릭, Enter/Space를 지원한다. Esc는 취소한다.
- 메모·도어락·완료 상태를 자동 저장한다. 퍼즐 도입 전의 다른 층 저장은 승강기 귀환 수단을 유지한다.

검증: `tests/floor17-power-circuit.mjs`, `tests/solar-ui.mjs`, `tests/elevator-power.mjs`, `tests/floor17-extension.mjs`.
