# Solar emergency distribution panel

- Generated with built-in `image_gen`.
- Source: `panel-source.png`, 1536×1024 RGBA, two horizontal 768×1024 cells.
- Runtime: `panel-off-on.png`, 768×512 RGBA, two horizontal 384×512 cells, nearest-neighbor resize with `scripts/prepare-solar-ui.ps1`.
- Frame 0: lever UP, OFF. Frame 1: lever DOWN, ON. Same canvas, cabinet anchor and baseline; genuine transparent outer margins. Front orthographic pixel art; labels and floor numbers are live HTML.
- `power.css` displays one cell; `js/interaction/power.js` selects the frame. The lever must be ON before selecting one floor. Lifting it disconnects the selected floor.
