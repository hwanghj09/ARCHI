# 벽 환풍구 에셋 (닫힘 → 빠루로 여는 중 → 열림) + 빠루

참고 사진의 루버형 환풍구(사각 프레임 + 가로 날개)를 기존 v3 흰 벽에 맞춰 만들었다.

- 프레임·날개는 벽보다 한 톤 어두운 분체도장 강판색이다.
- 빛 방향(좌상단), 부드러운 접촉 그림자, 날개 아래쪽 먼지를 벽과 같은 방식으로 넣었다.
- 문처럼 게임의 벽 배경 필터(brightness .72 / saturate .85)를 미리 구워 넣어서, 벽 위에 얹어도 밝기가 따로 놀지 않는다.

## 크기·배치

- 환풍구 본체: **120×96** 게임 px (약 1.3m×1m). 파일에는 사방 6px 여백(그림자용)이 있어 **132×108**이다.
- 세 상태 모두 **같은 캔버스·같은 위치**라 이미지만 바꿔 끼우면 된다. 위치를 다시 잡을 필요가 없다.
- 놓는 위치 예:

| 용도 | 아래 끝 위치 |
| --- | --- |
| 기어 들어가는 환풍구 | 바닥 근처 (아래 끝 y≈556 바로 위) |
| 단서를 숨기는 환풍구 | 눈높이 이상 (아래 끝 y≈420) |

- 흰 기본벽(`wall-concrete`) 위에 쓰는 것을 기준으로 만들었다. 유리벽 위에는 달지 않는 것이 자연스럽다.

## 상호작용 흐름 예

1. `vent-closed` 표시. 플레이어가 빠루 없이 조사하면 "나사로 단단히 고정되어 있다" 같은 메시지를 띄운다.
2. 빠루를 가진 상태로 조사하면 `vent-prying`으로 바꾸고 짧게 흔들거나 효과음을 낸다(약 0.5~1초).
3. `vent-open`으로 바꾼다. 같은 자리에 `vent-cover-removed`를 바닥 쪽으로 떨어뜨린다(살짝 회전, 아래 끝을 바닥선 570에 맞춤).
4. 열린 뒤에는 덕트 안 아이템 획득이나 이동 같은 상호작용을 연결한다.

```css
/* 예: fixture 하나로 상태 전환 */
.fixture.wall-vent        { width: 132px; height: 108px; background: url('assets/objects/wall-vent/vent-closed.png') 0 0 / 100% 100% no-repeat; }
.fixture.wall-vent.prying { background-image: url('assets/objects/wall-vent/vent-prying.png'); }
.fixture.wall-vent.open   { background-image: url('assets/objects/wall-vent/vent-open.png'); }
```

## 게임 적용 (2026-10-24)

- `assets/objects/wall-vent/`에 두었다(여러 층에서 쓰는 공용 소품). 미리보기 `vent-states-preview.png`와 zip은 넣지 않았다.
- 지금은 `vent-open.png`만 쓴다: 층 설정 `fixtures`에 `{ style: 'wall-vent', hideSpot: true, x, y: 454, width: 132, height: 108 }`
  (구멍 아래 끝 y=556). 앞에 앉아서(Ctrl) E를 누르면 화면을 전환해 안에 숨고(#vent-view), 로봇이 보지도 붙잡지도 못한다.
  E로 나온다(js/scene/guard-patrol.js setVentHiding).
- `duct-view.png`(1920×1080): 숨은 동안 덮는 덕트 안 화면. 엘리베이터 칸처럼 한 점 투시로 철판 벽이 구멍으로 모이고, 구멍
  (x 509–1411, y 292–950)은 투명하고, 그 자리에 엘리베이터 칸 문틈처럼 그 장면의 배경 그림(복도 walls.png, 방은 천장·바닥·벽
  겹)을 바닥 쪽 380px만 2배로 잘라 보인다(환풍구의 `viewX`가 가운데). 가장 가까운 로봇은 환풍구와의 거리만큼 그 위에 2배 크기로 그린다.
  `source/make_duct_view.py`로 만든다(PIL만 사용).
- 배치·바깥 풍경 고르기·확인 사진은 스킬 `.claude/skills/archi-wall-vent`를 따른다(복도마다 하나, 어울리는 방에만).
- 덮개 뜯기(js/interaction/vent-pry.js): 처음엔 `vent-closed`. 빠루(`f17-crowbar`)를 가지고 E를 누르면 `vent-prying`으로 바뀌고,
  수호가 오른쪽에 웅크려 `crowbar.png`(좌우 뒤집어 날 끝을 오른쪽 아래 모서리에)를 끼운 채 타이밍 스킬체크(한 바퀴 0.7초로
  빠르게 도는 바늘이 흰 칸에 있을 때 스페이스·Enter, 반응속도)를 맞춘다. 앞쪽 끝 노란 완벽 칸은 한 번, 흰 칸은 두 번
  (연속 아니어도 된다). 그러면 `vent-open`이 되고 `vent-cover-removed`가 왼쪽 바닥으로 떨어져 기댄다. 연 상태는 `vent-open:<장면>@<x>`로 저장된다.
