- Generator: built-in image_gen.

## Shared prompt

Use case: stylized-concept. Create a production transparent pixel-art computer prop sprite sheet for ARCHI, a 2D side-scrolling office mystery game. The attached image is a STYLE REFERENCE ONLY: restrained crisp pixel clusters, realistic office hardware, subtle worn edges. Generate a NEW distinct computer design. Exactly two equal square cells in a horizontal 2-column 1-row sheet, 2:1 aspect ratio. LEFT power OFF, RIGHT power ON. Both states must have precisely identical hardware, silhouette, scale, position, and bottom baseline within their cell. Straight-on front elevation, very slight top visibility on keyboard, no isometric perspective. Complete isolated objects with generous margins. Actual transparent alpha in all empty areas. No desk, floor, room, people, drop shadows, checkerboard, cell borders, captions, logos or watermark. Keep screen graphics legible at small sprite scale, use simple graphic shapes rather than readable tiny text. NO code, terminal, programming windows or source code. Screen content is painted into the bitmap. Output only the finished sprite sheet.
