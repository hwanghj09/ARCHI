# 밀기 상자 원본

`ramen-box.png`는 image_gen으로 새로 그린 골판지 상자입니다. 횡스크롤 게임에 맞춰 윗면·옆면이 보이지 않는 평면 측면도로 그렸습니다. 상단과 바닥이 수평이고 양쪽 모서리가 수직인 글자 없는 상자입니다. 투명도를 정리하고 568×357로 내보낸 파일이 상위 폴더의 런타임 이미지입니다.

게임에서는 `js/core/brands.js`의 `BRAND_NAMES.ramen`과 `ramenEnglish`를 평평한 면 중앙에 수평으로 표시합니다. 기본 표기는 **인라면 / IN RAMEN**입니다. 상자 자체를 다른 그림으로 바꾸려면 같은 파일의 `BRAND_ART.ramenBox`를 수정합니다. 기존 186×117 충돌체와 밀기 범위는 유지합니다.
